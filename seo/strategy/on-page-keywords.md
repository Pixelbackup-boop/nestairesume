## Keyword Placement Summary Per Page

### Every page MUST have:

1. **Meta description** containing: "resume example", "resume format", "professional", "template"
2. **Tags array** with 8-10 tags including universal keywords
3. **Opening paragraph** using "resume example" and "resume format"
4. **"Resume Format & Template Tips" section** (H2) — primary home for 5M "resume format" keyword
5. **ATS section** using "ats resume template", "ats resume format"
6. **CTA paragraph** using "resume template", "professional resume", "write a resume"

### Keyword density targets:

| Keyword | Times per page |
|---------|---------------|
| resume format | 4-6 |
| resume example | 3-5 |
| resume template | 2-4 |
| professional resume | 2-3 |
| cv example / cv format | 1-2 |
| ats resume | 1-2 |
| write a resume | 1 |

### Tags template:
```
tags: [
  "[job title] resume",
  "[job title] resume example",
  "[job title] resume template",
  "[job title] cv example",
  "resume format",
  "professional resume",
  "ats resume template",
  "resume writing guide"
]
```

### Meta description template:
```
"[Job Title] resume example with professional resume format and templates. [1-sentence value prop]. Free writing guide with ATS-friendly tips."
```
