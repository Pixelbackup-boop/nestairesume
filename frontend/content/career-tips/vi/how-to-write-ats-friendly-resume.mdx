## CV Thân Thiện ATS: Điểm Chính

- 75% CV bị loại trước khi đến tay nhà tuyển dụng do không qua ATS
- Từ khóa từ JD là yếu tố quan trọng nhất cho ATS
- Bố cục đơn giản, heading chuẩn, font hệ thống là nền tảng
- PDF text-based là định dạng an toàn nhất
- Kiểm tra ATS trước khi gửi bằng [ATS Checker](/vi/ats-checker)

## ATS Là Gì và Tại Sao Quan Trọng

ATS (Applicant Tracking System) là phần mềm sàng lọc CV tự động. Tại Việt Nam 2026, khoảng 60% doanh nghiệp lớn và hầu hết công ty đa quốc gia sử dụng ATS. CV không tương thích ATS = CV không bao giờ được đọc.

Xem chi tiết: [ATS là gì — hướng dẫn đầy đủ](/vi/blog/ats-la-gi-huong-dan)

## 7 Nguyên Tắc CV Chuẩn ATS

### 1. Heading Chuẩn

ATS tìm kiếm heading tiêu chuẩn:
- "Tóm Tắt Chuyên Môn" / "Professional Summary"
- "Kinh Nghiệm Làm Việc" / "Work Experience"
- "Học Vấn" / "Education"
- "Kỹ Năng" / "Skills"
- "Chứng Chỉ" / "Certifications"

Tránh heading sáng tạo: "Hành Trình Của Tôi", "Siêu Năng Lực" — ATS không nhận diện.

### 2. Tối Ưu Từ Khóa

Đọc JD kỹ và đưa vào CV:
- **Kỹ năng cứng:** "quản lý dự án", "phân tích dữ liệu", "Python"
- **Chứng chỉ:** "PMP", "IELTS 7.5", "AWS Certified"
- **Phần mềm:** "SAP", "Salesforce", "Google Analytics"
- **Viết cả hai phiên bản:** "Quản lý dự án (Project Management)"

### 3. Bố Cục Đơn Giản

- **Bố cục 1 cột** — An toàn nhất
- **Không dùng bảng, text box, hoặc columns**
- **Không đặt thông tin trong header/footer**
- **Bullet points đơn giản** (dấu gạch ngang hoặc bullet tròn)

### 4. Font Tiêu Chuẩn

| Font | Đánh giá |
|------|---------|
| Arial | Rất an toàn |
| Calibri | Rất an toàn |
| Roboto | An toàn |
| Times New Roman | An toàn |
| Font thư pháp | Không an toàn |

### 5. Định Dạng File

PDF text-based là lựa chọn tốt nhất. Kiểm tra: mở PDF → thử select text → nếu select được = ATS đọc được.

### 6. Tên File Rõ Ràng

Format: "Ho-Ten-Chuc-Danh-CV.pdf"
Ví dụ: "Nguyen-Van-An-Marketing-Manager-CV.pdf"

### 7. Kiểm Tra Trước Khi Gửi

- Dùng [ATS Checker](/vi/ats-checker) để kiểm tra điểm tương thích
- So khớp từ khóa CV với JD — mức tối thiểu 60%
- Lưu dạng plain text (.txt) — nếu đọc được = ATS đọc được

## Checklist CV Chuẩn ATS

- [ ] Heading tiêu chuẩn (không sáng tạo)
- [ ] Từ khóa khớp ≥60% với JD
- [ ] Bố cục 1 cột, không bảng/text box
- [ ] Font hệ thống, cỡ ≥10pt
- [ ] PDF text-based
- [ ] Tên file rõ ràng
- [ ] Không header/footer cho thông tin quan trọng
- [ ] Song ngữ Việt-Anh cho thuật ngữ kỹ thuật
