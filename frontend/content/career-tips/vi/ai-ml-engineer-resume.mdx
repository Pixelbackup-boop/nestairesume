## CV ML Engineer: Điểm Chính

- ML Engineer khác Data Scientist: tập trung vào triển khai và vận hành model ở production
- Kỹ năng MLOps (Docker, Kubernetes, CI/CD cho ML) ngày càng quan trọng
- Dự án end-to-end từ data ingestion đến model serving ấn tượng nhất
- Metrics về performance (latency, throughput) quan trọng ngang accuracy

Hướng dẫn cv machine learning engineer này cung cấp các mẹo thực tế và ví dụ cụ thể giúp bạn nổi bật.

## ML Engineer vs Data Scientist vs AI Researcher

| Tiêu chí | ML Engineer | Data Scientist | AI Researcher |
|----------|-------------|---------------|---------------|
| Focus | Production systems | Analysis & insights | Novel algorithms |
| Kỹ năng chính | MLOps, Engineering | Statistics, Viz | Math, Theory |
| Output | Deployed models | Reports, dashboards | Papers, prototypes |
| Lương VN (Senior) | 40-70M VNĐ | 35-60M VNĐ | 45-80M VNĐ |

## Cấu Trúc CV ML Engineer

### Kỹ Năng Cần Highlight

**ML/DL Frameworks:** PyTorch, TensorFlow, scikit-learn, XGBoost, LightGBM
**MLOps:** MLflow, Kubeflow, Airflow, DVC, Weights & Biases
**Infrastructure:** Docker, Kubernetes, Terraform, AWS/GCP
**Data Engineering:** Spark, Kafka, dbt, Airflow
**Serving:** TorchServe, TensorFlow Serving, Triton, BentoML

### Bullet Points Mẫu

- "Xây dựng ML pipeline end-to-end xử lý 50M records/ngày, giảm thời gian training từ 8 giờ xuống 45 phút"
- "Triển khai A/B testing framework cho 5 ML models, tăng conversion rate 18%"
- "Tối ưu model serving giảm P99 latency từ 200ms xuống 30ms bằng ONNX Runtime"
- "Phát triển feature store phục vụ 20+ models real-time trên Feast + Redis"

## Kinh Nghiệm Dự Án

Mỗi dự án ghi rõ:
1. **Bài toán:** Recommendation, NLP, Computer Vision, Fraud Detection...
2. **Data:** Quy mô, nguồn, preprocessing
3. **Model:** Architecture, training approach
4. **Deployment:** Infrastructure, serving, monitoring
5. **Impact:** Business metrics cải thiện

## Thị Trường ML Engineer Việt Nam

Nhu cầu cao tại: VinAI, FPT AI, Zalo AI, Cốc Cốc, Momo, VNPay, Tiki, Shopee Vietnam. Lĩnh vực hot: NLP tiếng Việt, Recommendation Systems, Fraud Detection, Computer Vision.
