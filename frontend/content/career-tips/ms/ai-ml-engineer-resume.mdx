## Perbezaan Jurutera ML dan Jurutera AI

Walaupun sering digunakan secara bergantian, jurutera ML dan jurutera AI mempunyai fokus yang berbeza. Jurutera ML lebih tertumpu pada pembinaan, pengoptimuman, dan penggunaan model pembelajaran mesin dalam persekitaran pengeluaran. Resume jurutera ML perlu menonjolkan kecekapan dalam MLOps, kejuruteraan data, dan pengoptimuman prestasi model — bukan sekadar keupayaan melatih model.

Panduan resume jurutera ML ini direka untuk pasaran Malaysia di mana permintaan untuk pakar ML meningkat dengan pesat, terutamanya dalam sektor fintech, e-dagang, dan telekomunikasi.

## Komponen Utama Resume ML Engineer

### Ringkasan Profesional

Ringkasan anda perlu menunjukkan kedalaman teknikal dan impak perniagaan:

**Contoh Junior**: "Graduan Sains Data dari UTM dengan pengalaman praktikal dalam pembangunan pipeline ML menggunakan Python dan Scikit-learn. Menyiapkan projek pengkelasan imej buah-buahan tempatan Malaysia mencapai ketepatan 96% menggunakan CNN. Mahir dalam pengoptimuman model dan A/B testing."

**Contoh Mid-Level**: "ML Engineer dengan 4 tahun pengalaman membina dan menggunakan model ML dalam skala pengeluaran untuk platform e-dagang Malaysia. Membangunkan sistem cadangan produk yang meningkatkan kadar penukaran sebanyak 23%. Berpengalaman dalam MLOps end-to-end menggunakan Kubeflow, MLflow, dan AWS SageMaker."

**Contoh Senior**: "Senior ML Engineer dan arkitek MLOps dengan 7 tahun pengalaman memimpin transformasi ML di syarikat telekomunikasi Malaysia. Membina platform ML dalaman yang membolehkan 15 pasukan menggunakan model secara bebas. Mengurangkan kos infrastruktur ML sebanyak 40% melalui pengoptimuman sumber dan autoscaling."

## Kemahiran MLOps — Pembeza Utama

### Mengapa MLOps Penting

Di Malaysia, banyak syarikat sudah melampaui peringkat eksperimen ML dan memerlukan jurutera yang boleh mengurus model dalam pengeluaran. Kemahiran MLOps yang perlu ditonjolkan:

### Pipeline ML

- **Kubeflow** — orkestra pipeline ML di Kubernetes
- **Apache Airflow** — penjadualan dan automasi workflow data
- **MLflow** — penjejakan eksperimen, pengurusan model, dan penggunaan
- **DVC (Data Version Control)** — versi kawalan untuk data dan model

### Infrastruktur dan Pengkomputeran

- **Docker dan Kubernetes** — kontainerisasi dan orkestra
- **AWS SageMaker** — latihan dan penggunaan model di cloud
- **Google Vertex AI** — platform ML bersepadu
- **Terraform** — infrastruktur sebagai kod untuk sumber ML

### Pemantauan dan Penyelenggaraan

- **Model monitoring** — mengesan pergeseran data (data drift) dan penurunan prestasi
- **A/B testing** — membandingkan prestasi model secara langsung
- **Feature stores** — pengurusan ciri ML yang konsisten
- **CI/CD untuk ML** — penggunaan model secara automatik dan selamat

## Kejuruteraan Data untuk ML

### Mengapa Ia Penting dalam Resume

Jurutera ML yang baik bukan sahaja melatih model tetapi juga memahami data dari hulu ke hilir:

- **ETL/ELT pipelines** — mengekstrak, mengubah, dan memuat data
- **Data quality** — mengesan dan menangani data yang rosak atau tidak lengkap
- **Feature engineering** — mencipta ciri bermakna daripada data mentah
- **Data warehousing** — BigQuery, Redshift, atau Snowflake

### Konteks Malaysia

Data di Malaysia sering mempunyai ciri unik:
- **Teks berbilang bahasa** — BM, Inggeris, Mandarin, Tamil dalam satu set data
- **Nama dan alamat Malaysia** — format yang berbeza daripada standard antarabangsa
- **Data kewangan tempatan** — format RM, nombor IC, nombor akaun bank Malaysia
- **Pematuhan PDPA** — undang-undang perlindungan data peribadi Malaysia

Menyebut pengalaman menangani cabaran data khusus Malaysia dalam resume anda menunjukkan kefahaman mendalam yang dihargai oleh majikan tempatan.

## Projek yang Menonjol dalam Resume ML

### 1. Sistem Cadangan (Recommendation System)

Sangat dicari oleh platform e-dagang Malaysia seperti Shopee, Lazada, dan Zalora:
- Jenis model yang digunakan (collaborative filtering, content-based, hybrid)
- Metrik prestasi (CTR improvement, conversion rate)
- Skala (berapa banyak pengguna/produk)

### 2. Sistem Pengesanan Penipuan

Penting untuk sektor kewangan Malaysia (Maybank, CIMB, RHB):
- Ketepatan dan kadar pengesanan
- Pengurangan kerugian dalam RM
- Masa pengesanan (real-time vs batch)

### 3. NLP untuk Bahasa Malaysia

Niche yang sangat bernilai kerana kekurangan sumber NLP untuk BM:
- Analisis sentimen untuk ulasan pelanggan Malaysia
- Chatbot berbilang bahasa
- Pengkelasan dokumen rasmi Malaysia

### 4. Ramalan dan Peramalan

Relevan untuk pelbagai industri di Malaysia:
- Ramalan permintaan untuk rantaian bekalan
- Ramalan churn pelanggan untuk telekomunikasi
- Ramalan harga hartanah di pasaran Malaysia

## Format dan Tips Resume ML

### 1. Bahagian Teknikal yang Teratur

Susun kemahiran teknikal dalam kategori yang jelas:

```
KEMAHIRAN TEKNIKAL
ML/DL: PyTorch, TensorFlow, Scikit-learn, XGBoost, LightGBM
MLOps: MLflow, Kubeflow, DVC, Weights & Biases
Cloud: AWS SageMaker, GCP Vertex AI, Azure ML
Data: Spark, Pandas, SQL, BigQuery, Airflow
Bahasa: Python, Scala, SQL, Bash
```

### 2. Kuantifikasi Segala-galanya

Setiap poin pengalaman perlu ada angka:
- "Melatih model" → "Melatih model gradient boosting pada 50M rekod yang mengurangkan churn pelanggan sebanyak 18%"
- "Membina pipeline" → "Membina pipeline ML automatik yang mengurangkan masa penggunaan model dari 2 minggu ke 4 jam"

### 3. Tunjukkan Impak Perniagaan

Perekrut Malaysia, terutama di syarikat bukan teknologi, ingin memahami impak perniagaan:
- Berapa banyak wang dijimatkan atau dihasilkan?
- Berapa banyak masa proses dipercepatkan?
- Berapa banyak pengguna yang mendapat manfaat?

### 4. Sertakan Pautan Teknikal

- GitHub dengan repositori ML yang terdokumentasi
- Blog teknikal atau artikel di Medium
- Profil Kaggle dengan kedudukan dan medal
