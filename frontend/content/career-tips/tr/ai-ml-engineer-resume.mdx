## AI/ML Mühendisi CV: Rekabetçi Teknoloji Piyasasında Öne Çıkın

Makine öğrenimi mühendisleri Türkiye'nin en hızlı büyüyen kariyer profesyonelleri arasında yer alıyor. Bu alana özgü CV stratejileri, generalist yazılım mühendisliği CV'lerinden farklı yaklaşım gerektirir.

Bu ai ml mühendisi cv rehberi, öne çıkmanıza yardımcı olacak pratik ipuçları ve gerçek örnekler sunar.

## ML Mühendisi CV'si Neye Benzemelidir?

Başarılı bir ML mühendisi CV'si şu soruları yanıtlamalıdır:

1. **Hangi ML tekniklerini biliyorsunuz?** (Supervised/Unsupervised/Reinforcement)
2. **Modelleri üretim ortamına nasıl taşıdınız?** (MLOps deneyimi)
3. **Gerçek iş etkisi ne oldu?** (Ölçülebilir metrikler)
4. **Hangi veri ölçeğiyle çalıştınız?** (Kayıt sayısı, hesaplama ölçeği)

## Teknik Beceriler Bölümü: ML Özel Format

```
ML Framework'leri:
PyTorch (ileri düzey), TensorFlow/Keras (orta düzey),
Scikit-learn (ileri düzey), XGBoost/LightGBM (ileri düzey)

Üretken AI / LLM:
OpenAI API, LangChain, Hugging Face Transformers,
Fine-tuning (LoRA, PEFT), RAG sistemleri

MLOps:
MLflow, Weights & Biases, DVC, Kubeflow, Seldon Core

Veri / İşlem:
Apache Spark, Pandas, NumPy, SQL, dbt

Cloud ML Servisleri:
AWS SageMaker, GCP Vertex AI, Azure ML
```

## Deneyim Maddeleri: ML'e Özgü Örnekler

### Öneri Sistemi Projesi

**Zayıf:**
> E-ticaret için öneri algoritması geliştirdim.

**Güçlü:**
> 12M+ ürün ve 4M kullanıcılık e-ticaret platformu için collaborative filtering + içerik tabanlı hibrit öneri sistemi geliştirdim; ürün tıklama oranını %31 artırdı, A/B test ile doğrulandı (n=500K kullanıcı).

### Doğal Dil İşleme Projesi

**Zayıf:**
> NLP modeli ile metin analizi yaptım.

**Güçlü:**
> BERT tabanlı duygu analizi modeli fine-tuning ile Türkçe sosyal medya verisine uyarladım; sınıflandırma doğruluğunu baseline %74'ten %89'a çıkardım, günlük 200K tweet işleyen üretim API'si olarak yayınlandı.

### MLOps ve Üretim

**Zayıf:**
> ML modellerinin bakımını yaptım.

**Güçlü:**
> MLflow + Seldon Core ile 15 modeli kapsayan ML servisi altyapısı kurdum; model yeniden eğitim süresini 6 saatten 45 dakikaya indirdim, sürüm yönetimi ve otomatik rollback mekanizması oluşturdum.

## ML Kariyeri Türkiye'de: Yol Haritası

### Kariyer Seviyeleri

| Seviye | Yıl Deneyim | Beklenen Beceriler |
|--------|-------------|-------------------|
| Junior ML Engineer | 0-2 yıl | Python, temel ML, kurs projeleri |
| Mid-Level ML Engineer | 2-5 yıl | Üretim deneyimi, MLOps, etki metrikleri |
| Senior ML Engineer | 5+ yıl | Mimari kararlar, ekip yönlendirme, ölçek |
| ML Tech Lead | 7+ yıl | Strateji, bütçe, çok disiplinli koordinasyon |

### Türkiye'de En Çok Aranan ML Rolleri (2026)

- **LLM Mühendisi / Prompt Engineer:** Üretken AI uygulamaları için
- **MLOps Mühendisi:** Model operasyonları ve platform
- **Veri Bilimci:** Analitik ve deneyim odaklı
- **Bilgisayar Görüsü Mühendisi:** Görüntü işleme, endüstriyel AI
- **NLP Mühendisi:** Türkçe dil modelleri için özel talep

## ATS Optimizasyonu: ML İlanlarında Aranan Kelimeler

Türkiye'deki ML ilanlarında en sık geçen anahtar kelimeler:

```
machine learning, derin öğrenme, neural network,
python, pytorch, tensorflow, scikit-learn,
veri bilimi, data science, mlops, model deployment,
llm, large language model, generative ai, nlp,
aws sagemaker, azure ml, gcp vertex ai,
computer vision, recommendation system
```

**İpucu:** Hem Türkçe hem İngilizce terimleri kullanın — ilanlar İngilizce teknik terim arar.
