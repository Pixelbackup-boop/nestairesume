## AI Mühendisi CV: Türkiye Teknoloji Sektöründe Öne Çıkın

Yapay zeka alanındaki kariyer fırsatları Türkiye'de hızla artıyor. Teknoparklar, fintech unicorn'ları ve çok uluslu şirketler nitelikli AI mühendisi arıyor. Ancak bu alanda CV yazmak farklı bir strateji gerektirir — teknik yetkinlikler kanıtlanabilir olmalı, sorumluluklar değil başarılar öne çıkmalıdır.

## AI Mühendisi CV Yapısı

### 1. Profesyonel Özet (3-4 Cümle)

```
[X] yıllık AI/ML deneyimiyle [uygulamaları/modelleri] geliştiren
Yapay Zeka Mühendisi. [Şirket/proje]'de [model türü] modeli kullanarak
[ölçülebilir sonuç] elde ettim. Python, PyTorch ve AWS SageMaker ile
üretim ortamında [özellik] çözümleri inşa etme konusunda uzmanlık.
```

### 2. Teknik Beceriler (Kategorilere Ayırın)

**Programlama:** Python, R, SQL, Scala

**ML Framework'leri:** TensorFlow, PyTorch, Scikit-learn, Hugging Face Transformers

**Üretken AI:** LangChain, LlamaIndex, OpenAI API, RAG, Fine-tuning

**MLOps:** MLflow, Kubeflow, DVC, GitHub Actions

**Cloud / Altyapı:** AWS SageMaker, GCP Vertex AI, Azure ML, Docker, Kubernetes

**Veri Mühendisliği:** Apache Spark, dbt, Snowflake, Airflow

### 3. İş Deneyimi — Güçlü Madde İşareti Örnekleri

**Zayıf:**
> LLM modelleri ile çalıştım.

**Güçlü:**
> RAG mimarisi ile kurumsal bilgi tabanı üzerine LLM uygulaması geliştirdim; 500+ kullanıcı için müşteri hizmetleri sorgularının %67'sini otomatikleştirdim, yanıt süresini 4.2s'den 0.8s'ye düşürdüm.

**Zayıf:**
> Model eğitimi yaptım.

**Güçlü:**
> Özel nesne tanıma modelini (YOLOv8 üzerinde fine-tuning) üretim hattına entegre ederek kalite kontrol hata tespitini manuel sürecin %92 üzerine çıkardım, yıllık 1.2M TL iş gücü tasarrufu sağladım.

## Sektöre Göre AI Rolleri (Türkiye)

| Sektör | Tipik Roller | Öne Çıkan Beceriler |
|--------|-------------|---------------------|
| Fintech | Risk modelleme, sahtekarlık tespiti | Sklearn, XGBoost, açıklanabilir AI |
| E-ticaret | Öneri sistemleri, arama optimizasyonu | Collaborative filtering, Elasticsearch |
| Sağlık Tech | Görüntü analizi, hastalık tahmini | CNN, PyTorch Medical, DICOM |

## GitHub Profilini CV'ye Entegre Etme

AI mühendisleri için GitHub profili CV kadar önemlidir:

- README dosyasını portfolyoya dönüştürün
- Her projeye: Problem açıklaması + kullanılan teknoloji + sonuç ekleyin
- Aktif katkı grafiği (contribution graph) sürekliliği gösterir
- Proje yıldız sayısı topluluk onayını yansıtır

**CV'deki link formatı:**
> GitHub: github.com/[kullanıcıadı] | Hugging Face: huggingface.co/[kullanıcıadı]

## AI Mühendisi CV'sinde ATS Optimizasyonu

İlan analizine göre en sık aranan anahtar kelimeler:

- `machine learning`, `derin öğrenme` / `deep learning`
- `large language model`, `LLM`, `generative AI`
- `model deployment`, `MLOps`, `inference`
- Spesifik framework adları: PyTorch, TensorFlow, scikit-learn
- Cloud provider adları: AWS, GCP, Azure

**İpucu:** Hem İngilizce hem Türkçe terimleri kullanın — Türkçe ilanlar bile teknik kelimeleri İngilizce arar.
