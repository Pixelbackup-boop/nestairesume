## ML Engineer CV: Kernpunten

- ML engineer en data scientist zijn verschillende rollen — benoem je focus duidelijk
- Productie ML-ervaring (MLOps, model deployment) is hoog gewaardeerd boven puur onderzoek
- Kwantificeer modelperformance: accuracy, F1-score, AUC, latency, throughput
- Open-source bijdragen en Kaggle-prestaties zijn sterke differentiators
- Bedrijven betalen in 2026 €80K-€130K+ voor senior ML engineers in Nederland

Deze machine learning engineer cv gids biedt praktische tips en concrete voorbeelden om op te vallen.

## ML Engineer vs. Data Scientist: Weet het Verschil

| Rol | Focus | Typische Tools |
|-----|-------|----------------|
| ML Engineer | Model deployment, MLOps, schaalbaarheid | PyTorch, Kubernetes, MLflow, Docker |
| Data Scientist | Analyse, experiment, modelbouw | Python, R, Jupyter, sklearn |
| Data Engineer | Data pipelines, infrastructuur | Spark, Airflow, dbt, SQL |

Jouw cv moet duidelijk maken welke rol je invult.

## Vereiste Vaardigheden 2026

### Core ML Engineering

- **Frameworks:** PyTorch, TensorFlow, JAX, Hugging Face Transformers
- **MLOps:** MLflow, Kubeflow, Weights & Biases, Seldon, BentoML
- **Containerisatie:** Docker, Kubernetes, Helm
- **Feature Stores:** Feast, Tecton, Hopsworks
- **Monitoring:** Evidently, Arize, WhyLabs (model drift detectie)

### Data Engineering Overlap

- SQL (Postgres, BigQuery, Redshift)
- Spark / Databricks
- Airflow of Prefect (workflow orchestration)
- dbt voor data transformatie

### Toenemend Belang in 2026

- **LLM fine-tuning:** LoRA, PEFT, RLHF
- **RAG-architecturen:** Vector databases (Pinecone, Weaviate, pgvector)
- **AI Governance:** Model cards, bias audits, GDPR-compliance voor ML

## CV-Structuur voor ML Engineers

### Professionele Samenvatting

Benoem je specialisatie, primaire stack, en 1-2 kernprestaties:

"ML Engineer met 5 jaar ervaring in productie recommender systems bij e-commerce. Bouwde en deployde een real-time personalisatiesysteem (PyTorch, Kubernetes) dat CTR met 23% verhoogde en €4M extra omzet genereerde. Expertise in MLOps, A/B testing en feature engineering. Zoek een ML-lead rol."

### Werkervaring: Focus op Productie-impact

Sterk bullet: "Migreerde batch-inferentie naar real-time serving architectuur (FastAPI + Triton), reduceerde latency van 800ms naar 45ms p99 en maakte 10x schaling mogelijk tijdens piekverkeer."

Zwak bullet: "Werkte aan verbetering van het aanbevelingssysteem."

### Projecten Sectie

Essentieel voor ML engineers:
- Kaggle: vermeld competitiepositie (top X%)
- GitHub: link + sterren/forks van populaire repos
- Publicaties of preprints (ArXiv)
- Open-source bijdragen (PyTorch, Hugging Face, scikit-learn)

### Certificeringen

- AWS Machine Learning Specialty
- Google Professional Machine Learning Engineer
- DeepLearning.AI TensorFlow Developer
- Databricks Certified ML Professional

## Salaris Benchmark (Nederland 2026)

- Junior ML Engineer (0-2 jaar): €55K-€75K bruto/jaar
- Medior ML Engineer (3-5 jaar): €75K-€100K bruto/jaar
- Senior ML Engineer (5+ jaar): €100K-€135K bruto/jaar
- ML Tech Lead / Principal: €130K-€180K+ bruto/jaar
