## Checklist CV ATS-Friendly: Panduan Optimasi 5 Menit

Lebih dari 75% perusahaan besar di Indonesia sudah menggunakan Applicant Tracking System (ATS) untuk menyaring CV sebelum ditinjau manusia. Kandidat yang memenuhi syarat bisa ditolak hanya karena format CV-nya membingungkan parser ATS. Checklist cepat ini memastikan CV Anda lolos filter otomatis setiap saat.

**Butuh strategi lengkap?** Untuk panduan ATS komprehensif dengan contoh dan template, lihat [panduan lengkap CV ATS kami](/id/blog/cara-membuat-cv-ats-friendly).

---

## ✅ Checklist Format CV ATS (Bagian Kritis)

### Format File
- [ ] Simpan sebagai **PDF** (atau .docx jika diminta)
- [ ] Ukuran file **di bawah 2MB**
- [ ] Nama file profesional: `NamaAnda-CV-Posisi.pdf`
- [ ] Tidak ada enkripsi atau password pada file

### Layout & Struktur
- [ ] **Layout satu kolom** atau dua kolom sederhana
- [ ] **Tidak ada text box** — gunakan paragraf biasa
- [ ] **Tidak ada tabel** untuk layout (hanya untuk data tabular yang sederhana)
- [ ] **Tidak ada header/footer** yang berisi informasi penting
- [ ] **Tidak ada grafik, chart, atau ikon** yang mewakili teks
- [ ] Margin **minimal 0.5 inci** (jangan terlalu sempit)

### Font & Typography
- [ ] Font standar: **Arial, Calibri, Times New Roman, atau Georgia**
- [ ] Ukuran font **10-12pt** untuk isi teks
- [ ] Heading **12-14pt**, konsisten
- [ ] Tidak ada font dekoratif atau script

---

## ✅ Checklist Kata Kunci ATS

### Sumber Kata Kunci
- [ ] Baca deskripsi pekerjaan dengan teliti
- [ ] Daftar 10-15 kata kunci paling sering muncul
- [ ] Sertakan **variasi dan sinonim** (misal: "manajemen proyek" dan "project management")
- [ ] Gunakan **singkatan DAN istilah penuh** (mis. "HRD (Human Resources Development)")

### Penempatan Kata Kunci
- [ ] Kata kunci utama ada di **ringkasan profesional**
- [ ] Kata kunci teknis ada di **bagian keterampilan**
- [ ] Kata kunci kontekstual ada di **bullet point pengalaman**
- [ ] Tidak ada keyword stuffing — harus terasa natural

### Heading Section yang ATS-Friendly
Gunakan heading standar ini (parser ATS mengenali istilah-istilah ini):

| ✅ Gunakan | ❌ Hindari |
|-----------|-----------|
| Pengalaman Kerja | Perjalanan Karier |
| Pendidikan | Latar Belakang Akademik |
| Keterampilan | Keahlian Spesial |
| Ringkasan Profesional | Tentang Saya |
| Sertifikasi | Pencapaian Profesional |

## ✅ Checklist Konten CV

### Informasi Kontak
- [ ] Nama lengkap di bagian paling atas
- [ ] Nomor telepon (aktif WhatsApp)
- [ ] Alamat email profesional
- [ ] Kota domisili (tidak perlu alamat lengkap)
- [ ] LinkedIn URL (opsional tapi direkomendasikan)

### Pengalaman Kerja
- [ ] **Urutan kronologis terbalik** (paling baru di atas)
- [ ] Setiap posisi: nama perusahaan, jabatan, periode, kota
- [ ] **3-6 bullet point** per posisi dengan kata kerja aksi
- [ ] Minimal **satu metrik terukur** per posisi

### Keterampilan
- [ ] Dikelompokkan berdasarkan kategori
- [ ] Mencakup hard skills AND soft skills yang relevan
- [ ] Sertakan tools dan software yang benar-benar dikuasai

## ⚠️ Elemen yang Harus Dihindari

Elemen-elemen ini sering **merusak parsing ATS**:

- ❌ **Foto embedded** dalam teks (simpan di header terpisah)
- ❌ **Hyperlink yang panjang** — gunakan teks anchor yang pendek
- ❌ **Karakter khusus** seperti ✓, ★, ♦ sebagai bullet (gunakan • biasa)
- ❌ **Multi-kolom** dengan text box yang terpisah
- ❌ **Watermark** atau gambar latar belakang
- ❌ **Teks dalam gambar** (tidak terbaca ATS)

## 🔍 Test ATS Sederhana

Sebelum submit, lakukan test ini:

**Test 1 — Copy-Paste Test:**
Salin semua teks CV ke Notepad atau Google Docs polos. Jika terbaca dengan struktur yang logis, ATS kemungkinan bisa membacanya.

**Test 2 — Tools Online:**
- Gunakan tools gratis di [ATS Checker kami](/id/tools/ats-checker)
- Atau coba Jobscan.co untuk analisis mendalam

**Test 3 — Keyword Match:**
Bandingkan kata kunci di CV dengan deskripsi pekerjaan — targetkan 70%+ kecocokan.
