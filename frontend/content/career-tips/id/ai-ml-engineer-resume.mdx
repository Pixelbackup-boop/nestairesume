## CV ML Engineer: Poin Kunci

- Bedakan dengan jelas antara proyek riset dan proyek production — rekruter industri lebih menghargai yang terakhir
- Sertakan metrik model (accuracy, F1, AUC) DAN metrik bisnis (revenue impact, cost savings, latency)
- Dokumentasikan skala sistem: jumlah data, traffic, infrastruktur yang dikelola
- Tunjukkan kemampuan end-to-end: dari data ingestion hingga model monitoring
- Link ke GitHub, Kaggle, atau demo proyek yang bisa diakses rekruter

## Posisi ML Engineer di Indonesia 2026

Permintaan untuk Machine Learning Engineer di Indonesia tumbuh signifikan, didorong oleh ekspansi perusahaan tech seperti Tokopedia, Gojek, Traveloka, dan ratusan startup berbasis AI. Namun, pasokan talent yang memenuhi kualifikasi masih terbatas — menciptakan peluang besar bagi kandidat yang bisa menunjukkan kombinasi kemampuan modeling dan engineering yang solid.

## Template CV ML Engineer

### Bagian Wajib (Urutan yang Disarankan)

**1. Header dengan Link Profesional**
```
Nama Lengkap — ML Engineer
email@domain.com | +62-xxx-xxx | GitHub: /username | Kaggle: /username
LinkedIn: /in/username | Jakarta Selatan, Indonesia
```

**2. Professional Summary**

Untuk 3-5 tahun pengalaman:
> "ML Engineer dengan spesialisasi computer vision dan NLP, berpengalaman membangun dan men-deploy model ke production di skala jutaan inferensi per hari. Menggunakan PyTorch dan AWS SageMaker, berkontribusi pada sistem rekomendasi yang meningkatkan ARPU 15% di platform streaming dengan 8M+ subscribers. Passionate tentang MLOps dan reproducible ML systems."

**3. Technical Skills**

Kelompokkan berdasarkan domain:
```
ML Frameworks:    PyTorch, TensorFlow, JAX, scikit-learn, XGBoost, LightGBM
MLOps & Infra:    MLflow, Kubeflow, Airflow, Docker, Kubernetes, Terraform
Cloud:            AWS (SageMaker, Lambda, ECS), GCP (Vertex AI, BigQuery)
Data:             Spark, dbt, Kafka, PostgreSQL, Redis, Feature Store
Languages:        Python (expert), SQL (advanced), Go (intermediate)
Monitoring:       Prometheus, Grafana, Evidently AI, WhyLabs
```

**4. Pengalaman (Format STAR dengan Metrik Ganda)**

Setiap pengalaman harus mencakup:
- **Konteks**: Apa yang dibangun dan untuk apa
- **Skala teknis**: Ukuran data, traffic, infrastruktur
- **Metrik model**: Accuracy, latency, throughput
- **Dampak bisnis**: Revenue, cost, efficiency

## Contoh Bullet Point yang Powerful

**Rekomendasi System:**
> "Re-architected recommendation engine dari collaborative filtering berbasis matrix factorization ke two-tower neural network (PyTorch), meningkatkan precision@10 dari 0.34 ke 0.51 dan mendorong peningkatan 19% pada GMV per session di platform marketplace"

**Fraud Detection:**
> "Membangun real-time fraud scoring pipeline menggunakan Kafka + Flink + XGBoost yang memproses 2.000 transaksi/detik dengan latency p99 < 50ms, mengurangi fraud rate 28% sambil mempertahankan false positive rate di bawah 0.3%"

**NLP/Text:**
> "Mengembangkan Indonesian intent classification model (IndoBERT fine-tuned) untuk customer service chatbot, mencapai 94% accuracy pada 87 intent kelas, menggantikan rule-based system yang butuh maintenance manual 40 jam/minggu"

**Computer Vision:**
> "Memimpin pengembangan OCR pipeline untuk ekstraksi KTP dan NPWP, menggabungkan CRAFT (text detection) + TrOCR (recognition), mencapai akurasi karakter 98.7% pada 15.000 dokumen/hari"

## Perbedaan CV Berdasarkan Target Posisi

### ML Engineer — Startup / Scale-up
- Tonjolkan kemampuan full-stack ML: dari EDA hingga deployment
- Sertakan pengalaman bekerja dengan data yang tidak sempurna
- Tunjukkan fleksibilitas: bisa ganti stack sesuai kebutuhan

### ML Engineer — Big Tech / Unicorn
- Fokus pada depth dan specialization di satu domain
- Sertakan pengalaman dengan sistem berskala sangat besar
- Tonjolkan kolaborasi lintas tim dan mentoring

### Research ML Engineer
- Cantumkan publikasi dan conference submissions
- Sertakan contribution ke open source ML projects
- Tonjolkan kemampuan novelty dan state-of-the-art benchmarking

## Checklist Sebelum Mengirim CV

- [ ] Setiap pengalaman memiliki minimal satu angka (persentase, skala, atau dampak finansial)
- [ ] Skills teknis sesuai dengan yang diminta di job description
- [ ] GitHub profile terbuka dan repositori yang di-pin relevan
- [ ] Tidak ada typo di nama tool/library (PyTorch bukan Pytorch, TensorFlow bukan Tensorflow)
- [ ] CV dalam format PDF dengan font standar (tidak ada grafik kompleks)
- [ ] Email profesional (hindari nickname yang tidak profesional)
- [ ] Total panjang: 1-2 halaman (tidak lebih)
