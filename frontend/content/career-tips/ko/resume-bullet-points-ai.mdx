## AI로 이력서 성과 문장 만들기: 불릿 포인트 완벽 가이드

이력서 불릿 포인트(성과 문장)는 채용 담당자가 가장 집중적으로 보는 부분입니다. AI를 활용해 효과적인 성과 문장을 만드는 방법을 안내합니다.

## 나쁜 불릿 vs 좋은 불릿

### 나쁜 예시 (업무 나열형)

- ❌ 마케팅 업무를 담당했습니다
- ❌ 고객 관리를 수행했습니다
- ❌ 데이터 분석 작업을 했습니다
- ❌ 프로젝트에 참여했습니다

### 좋은 예시 (성과 중심형)

- ✅ B2B 마케팅 캠페인 12건 기획·실행, 분기 리드 200% 증가(50건 → 150건) 달성
- ✅ VIP 고객 50명 전담 관리, 고객 이탈률 15% → 5%로 감소, 연 매출 3억 유지에 기여
- ✅ Python 기반 매출 예측 모델 개발, 예측 정확도 85% 달성, 재고 비용 월 2,000만 원 절감
- ✅ 신규 ERP 도입 프로젝트 리드(팀원 8명), 예산 내 3개월 조기 완료

## 성과 문장 작성 공식

### XYZ 공식

**X(행동) + Y(정량적 결과) + Z(맥락/방법)**

```
마케팅 캠페인 기획·실행(X)으로
분기 리드 200% 증가 달성(Y),
콘텐츠 마케팅과 LinkedIn 광고 전략 활용(Z)
```

### 직무별 성과 문장 예시

**개발자:**
- API 응답 시간 2초 → 200ms로 90% 단축, 마이크로서비스 아키텍처 전환으로 달성
- CI/CD 파이프라인 구축, 배포 주기 월 1회 → 일 3회로 단축, 버그 수정 속도 5배 향상

**마케팅:**
- 검색 엔진 최적화(SEO) 전략 수립, 오가닉 트래픽 월 50만 → 150만 달성 (6개월)
- 이메일 마케팅 자동화 도입, 오픈율 15% → 32% 향상, 전환율 3배 증가

**영업:**
- 신규 B2B 고객 50곳 개발, 연간 매출 20억 원 신규 창출
- 기존 고객 리텐션 프로그램 도입, 갱신율 75% → 92% 향상

**디자이너:**
- 앱 UI 리디자인, 사용자 이탈률 40% → 18% 감소, App Store 평점 3.8 → 4.6 상승
- 디자인 시스템 구축(컴포넌트 200개), 디자인-개발 핸드오프 시간 60% 단축

**인사/HR:**
- 채용 프로세스 개선, 평균 채용 기간 45일 → 28일 단축, 지원자 만족도 90% 달성
- 온보딩 프로그램 도입, 신규 직원 3개월 이내 이탈률 25% → 8% 감소
