## 커리어 개발 계획: 체계적인 경력 성장 전략

커리어 개발 계획은 "운 좋은 이직"이 아닌 "전략적 성장"을 가능하게 합니다. 1년·3년·5년 단위의 커리어 로드맵 작성법을 안내합니다.

## 커리어 개발 계획 5단계

### 1단계: 현재 위치 분석

자신의 현재 상태를 객관적으로 파악합니다:

- **보유 스킬** — 기술적 역량, 소프트 스킬 목록 작성
- **경력 수준** — 주니어/미드/시니어/리드
- **강점·약점** — SWOT 분석
- **시장 가치** — 현재 연봉 vs 시장 평균
- **만족도** — 직무, 회사, 성장 속도에 대한 만족

### 2단계: 목표 설정 (SMART)

| 기간 | 목표 예시 |
|------|----------|
| 1년 | "데이터 분석 자격증 취득, SQL 고급 수준 달성" |
| 3년 | "시니어 마케터 승진, 팀 리딩 경험 확보" |
| 5년 | "마케팅 팀장, 연봉 1억 달성" |

목표는 **S**pecific(구체적), **M**easurable(측정 가능), **A**chievable(달성 가능), **R**elevant(관련성), **T**ime-bound(기한)으로 설정합니다.

### 3단계: 갭 분석

현재 역량과 목표 사이의 차이를 파악합니다:

```
목표 역량: Python 고급, ML 기초, 팀 리딩
현재 역량: Python 중급, ML 초급, 팀 리딩 없음
갭:        Python 고급화, ML 중급 도달, 리딩 경험 필요
```

### 4단계: 액션 플랜

각 갭에 대한 구체적 행동 계획을 수립합니다:

- **교육**: 온라인 강의, 부트캠프, 대학원
- **자격증**: 직무 관련 국가공인·국제 자격증
- **프로젝트**: 사이드 프로젝트, 사내 프로젝트 참여
- **네트워킹**: 컨퍼런스, 커뮤니티, 멘토링
- **이직 준비**: 이력서 업데이트, 포트폴리오 정리

### 5단계: 실행과 점검

- **주간**: 학습 시간 확보 (최소 주 3시간)
- **월간**: 진행 상황 점검, 필요 시 계획 수정
- **분기**: 스킬 테스트, 포트폴리오 업데이트
- **연간**: 전면 재평가, 이력서 업데이트

## 직급별 커리어 개발 포인트

### 신입 (0-2년): 기초 확립

- 직무 스킬 숙달이 최우선
- 멘토 확보, 사내 교육 적극 참여
- 1가지 전문 분야 정하기
- 자격증 1-2개 취득

### 주니어 (2-5년): 전문성 심화

- 전문 분야에서 "이 사람이면 된다" 인정받기
- 사이드 프로젝트, 외부 발표 시작
- 리더십 소규모 경험 (프로젝트 리드)
- 이직 시장 가치 파악

### 시니어 (5-10년): 리더십 전환

- 기술 리더십 vs 매니지먼트 트랙 선택
- 팀 빌딩, 주니어 멘토링
- 업계 네트워크 확장
- 이직 or 승진 전략적 결정
