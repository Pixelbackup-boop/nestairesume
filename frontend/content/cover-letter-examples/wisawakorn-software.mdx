## Formatting & Structure Tips

Engineering managers and technical recruiters skim software cover letters in seconds, so your header should carry the signals they hunt for first: your primary stack (Python, JavaScript, React, Node.js), a GitHub or portfolio link, and — for a Thai software engineer applying to global, remote, or English-medium teams — your English working proficiency. Keep it to one page in a clean monospace-friendly or sans-serif font at 11pt; tech reviewers value clarity and signal-to-noise over decorative formatting, and a tidy letter mirrors clean code.

Anchor your two body paragraphs to engineering impact, not a feature laundry list. Quantify what a hiring manager weighs: "Cut API p95 latency from 800ms to 220ms by adding Redis caching and query indexing" or "Shipped a React/Node feature used by 50K monthly users and reduced AWS spend 30% by containerizing services with Docker." Tie each technology to an outcome rather than just naming it, and reference the specific systems in the posting — microservices, CI/CD pipelines, cloud infrastructure, or the framework versions they list. Link directly to a repo or live project that proves the work. If you're applying across borders, briefly note time-zone overlap and async collaboration experience. Close by inviting a technical conversation and pointing to where they can see your code.

## ATS Optimization

Many employers use Applicant Tracking Systems (ATS) to screen cover letters before a human reads them. To pass these filters, mirror keywords from the job description naturally throughout your letter. Avoid using headers in text boxes, tables, or graphics that ATS software cannot parse. Save your file as a PDF unless the employer specifically requests a different format.

Include the exact job title and key qualifications mentioned in the posting. If the role requires "project management experience," use that exact phrase rather than a synonym. This ensures your application scores well in automated screening while still reading naturally to hiring managers.
