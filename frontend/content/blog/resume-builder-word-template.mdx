Microsoft Word remains one of the most common tools for creating resumes. Over **60% of job seekers** use Word at some point in their job search. But Word is a general-purpose document editor — not a resume builder — and that distinction matters.

Here is how to create a professional, ATS-friendly resume in Word, plus when to consider a dedicated resume builder instead.

## How to Create a Resume in Word (Step-by-Step)

### Step 1: Open a Template or Start Blank

**Using a template:**
1. Open Microsoft Word
2. Click **File > New**
3. Search "resume" in the template search bar
4. Choose a simple, single-column template (avoid graphics-heavy designs)

**Starting blank (recommended for ATS):**
1. Open a new blank document
2. Set margins to 0.5-1 inch (Layout > Margins > Custom)
3. Choose a professional font (Calibri 11pt or Arial 10.5pt)

### Step 2: Add Your Sections

Use these exact headings (ATS systems look for standard section names):

```
CONTACT INFORMATION
PROFESSIONAL SUMMARY
WORK EXPERIENCE
EDUCATION
SKILLS
```

### Step 3: Format for ATS Compatibility

| Do | Don't |
|----|-------|
| Use standard section headings | Use creative heading names ("My Journey") |
| Single-column layout | Multi-column layouts or tables |
| Standard bullet points | Custom bullet characters or icons |
| Text directly on the page | Text inside text boxes or shapes |
| .docx or simple .pdf format | Headers/footers for contact info |
| 10.5-12pt professional font | Decorative fonts or font sizes below 10pt |

### Step 4: Add Content

**Contact information (top of page, no header/footer):**
```
Your Full Name
City, State | (555) 123-4567 | email@example.com | linkedin.com/in/yourname
```

**Professional summary (2-3 sentences):**
```
Results-driven [Job Title] with [X years] of experience in [specialty].
Proven track record of [key achievement with metric]. Seeking to leverage
[top skills] to contribute to [target company/role].
```

**Work experience (reverse chronological):**
```
Job Title | Company Name | City, State | Month Year – Present
• Achievement bullet with metric (e.g., "Increased revenue 25% by...")
• Achievement bullet with metric
• Achievement bullet with metric
```

### Step 5: Save and Export

- **Save as .docx** — This is the most ATS-compatible format
- **Save as PDF** — Use File > Save As > PDF for human readers
- **File name:** FirstName_LastName_Resume.docx

## Common Word Resume Mistakes

Avoiding these common mistakes will help your resume builder Word document perform well with ATS.

1. **Using tables for layout** — ATS systems often cannot read content inside Word tables correctly
2. **Putting contact info in headers/footers** — Many ATS systems skip headers and footers entirely
3. **Using text boxes** — Text inside Word text boxes may not be extracted by ATS parsers
4. **Choosing decorative templates** — Word templates with graphics, icons, and multi-column layouts are not ATS-safe
5. **Saving as .pdf from a complex template** — If the .docx uses tables/text boxes, the PDF inherits those ATS problems

## Step-by-Step: Creating a Resume from a Blank Word Document

Starting from scratch in Word gives you the most ATS-compatible result because you avoid hidden formatting artifacts that templates often carry. Here is exactly how to use a resume builder Word approach from a blank document.

### Setting Up the Document

1. Open Microsoft Word and click **Blank document**
2. Go to **Layout > Margins > Custom Margins** and set all four margins to **0.7 inches** (this gives you more space than the default 1-inch margins while keeping the document readable)
3. Go to **Layout > Size** and confirm the page size is **Letter (8.5" x 11")** for US applications or **A4** for international applications
4. Go to **Home > Font** and set the default font to **Calibri at 11pt** (or Arial 10.5pt if you prefer a sans-serif look)
5. Go to **Layout > Spacing** and set **Before: 0pt, After: 6pt, Line spacing: 1.0** (single spacing with a small gap between paragraphs)

### Adding Your Name and Contact Information

Do not use a Word header for your contact information — many ATS parsers skip the header area entirely.

1. Type your full name on the first line
2. Select your name, go to **Home > Font**, and set it to **14-16pt, Bold**
3. Press Enter and type your contact details on one line, separated by pipes: `City, State | (555) 123-4567 | email@example.com | linkedin.com/in/yourname`
4. Set this line to **10pt**, regular weight

### Creating Section Headings

1. Type your first section heading (e.g., "PROFESSIONAL SUMMARY")
2. Select the heading text and set it to **12pt, Bold, All Caps**
3. With the heading still selected, go to **Home > Borders** (the dropdown arrow) and select **Bottom Border** — this adds a clean horizontal line under the heading
4. Repeat for each section: WORK EXPERIENCE, EDUCATION, SKILLS

### Adding Work Experience Entries

For each position:
1. Type the job title in **Bold**, followed by a pipe, the company name, a pipe, the location, a pipe, and the date range — all on one line
2. Example: **Senior Marketing Manager** | Acme Corp | New York, NY | Jan 2022 – Present
3. Press Enter and insert bullet points using **Home > Bullets** (use the standard round bullet, not custom shapes)
4. Type 3-5 achievement-focused bullets starting with action verbs

### Saving Your Template for Reuse

After building your resume, save a reusable version:
1. Go to **File > Save As**
2. In the "Save as type" dropdown, select **Word Template (.dotx)**
3. Name it "Resume_Template" — Word will save it to your Templates folder
4. Next time you need a resume, go to **File > New > Personal** and select your template

## How to Use Word's Built-In Resume Templates

If you prefer a resume builder Word template rather than starting from a blank page, here is how to find and evaluate Word's built-in options.

### Accessing Templates

1. Open Word and click **File > New**
2. In the search bar at the top, type **"resume"** and press Enter
3. Word displays 20+ resume templates — scroll through the options
4. Click a template to see a preview, then click **Create** to open it

### Evaluating Templates for ATS Safety

Not all Word templates are ATS-compatible. Before choosing one, check for these red flags:

- **Multi-column layouts:** If the template uses two or three columns, ATS may read content across columns rather than within them. Stick to single-column templates
- **Text boxes:** Click on different sections of the template. If you see a blue border or selection handles, the text is inside a text box. ATS may not parse this content
- **Tables:** Right-click on the text area. If you see "Table Properties" in the menu, the template uses tables for layout. Some ATS handle simple tables, but many do not
- **Graphics and icons:** Templates with skill-level bars, icons for contact info, or decorative elements are not ATS-safe. These visual elements cannot be read by parsers

### Recommended Word Templates

The safest Word templates are the simplest ones. Look for:
- **"Basic resume"** — single column, no graphics
- **"Simple resume"** — clean layout with minimal formatting
- **"Chronological resume"** — standard reverse-chronological format

Avoid templates labeled "Creative," "Modern," or "Designer" — they typically use features that ATS cannot parse.

## Formatting Tips: Margins, Fonts, and Spacing in Word

Whether you use a resume builder Word template or start from scratch, getting the formatting details right makes the difference between a professional-looking resume and an amateur one. Here are the exact values to use.

### Margins

| Use Case | Top/Bottom | Left/Right |
|----------|-----------|------------|
| Standard (plenty of content) | 1 inch | 1 inch |
| Need more space | 0.7 inch | 0.7 inch |
| Maximum content (senior resumes) | 0.5 inch | 0.5 inch |

Never go below 0.5 inches — some printers clip content at the edges, and the document looks cramped.

### Font Choices and Sizes

| Element | Font | Size | Style |
|---------|------|------|-------|
| Your name | Calibri or Arial | 14-16pt | Bold |
| Section headings | Same as body font | 12pt | Bold, ALL CAPS |
| Job titles | Same as body font | 11pt | Bold |
| Body text | Calibri, Arial, or Garamond | 10.5-11pt | Regular |
| Company names/dates | Same as body font | 10.5-11pt | Regular or Italic |

**Do not mix more than two font families.** Using one font for everything is the safest approach. If you want variety, pair a serif heading font (like Garamond) with a sans-serif body font (like Calibri) — but never more than that.

### Line and Paragraph Spacing

- **Line spacing:** Set to 1.0 (single) or 1.08 for the body text. Double spacing wastes space and looks like a school paper
- **Paragraph spacing:** Set "After" spacing to 6pt. This adds a small gap between paragraphs without requiring blank lines
- **Between sections:** Add 12pt of space before each section heading to create visual separation

Access these settings through **Home > Line and Paragraph Spacing > Line Spacing Options** or **Layout > Spacing**.

## Exporting Your Word Resume as PDF

After using a resume builder Word setup, most job applications accept or prefer PDF format because it preserves your formatting across all devices and operating systems. Here is how to export correctly and why it matters.

### How to Save as PDF in Word

1. Click **File > Save As** (or File > Export on some versions)
2. In the "Save as type" dropdown, select **PDF (*.pdf)**
3. Before clicking Save, click **Options** and ensure "Document" is selected under "Publish what" and "Standard (publishing online and printing)" is selected for quality
4. Click **Save**

### Why PDF Matters for ATS

When you share a .docx file, the recipient's version of Word may render your formatting differently — fonts may substitute, spacing may shift, and your carefully designed layout may break. PDF locks the formatting in place.

However, there is a caveat: if your Word document uses text boxes, tables, or graphics for layout, the resulting PDF inherits those parsing problems. ATS reads the underlying structure, not the visual layout. A cleanly formatted .docx produces a cleanly parseable PDF. A complex .docx produces a problematic PDF.

### File Naming Conventions

Name your file professionally:
- **Correct:** `Sarah_Johnson_Resume.pdf` or `Sarah-Johnson-Marketing-Manager-Resume.pdf`
- **Incorrect:** `resume_final_v3_UPDATED.pdf`, `Resume (1).pdf`, or `my resume.pdf`

Include your name in the file name. Recruiters download dozens of resumes — a file named "resume.pdf" gets lost immediately.

## Word Resume Troubleshooting: Common Formatting Issues

These are the most frequent resume builder Word formatting problems and their fixes.

### Bullet Points Misaligning

**Problem:** Bullets at different indentation levels, or text wrapping unevenly.
**Fix:** Select all bullet text, right-click, choose **Adjust List Indents**. Set bullet position to 0.25 inches and text indent to 0.5 inches. Apply to the entire list for consistency.

### Page Breaks in the Wrong Place

**Problem:** A job title appears at the bottom of page 1 while its bullets start on page 2.
**Fix:** Place your cursor on the heading line, go to **Paragraph > Line and Page Breaks**, and check **Keep with next**. This forces the heading to stay with the content that follows it.

### Inconsistent Font Sizes After Pasting

**Problem:** Content pasted from another document carries its original formatting.
**Fix:** After pasting, click the paste options icon (or press Ctrl+Shift+V) and select **Keep Text Only**. Then reformat the text to match your resume's font and size settings.

### Resume Prints Differently Than on Screen

**Problem:** Margins, fonts, or spacing change when printing.
**Fix:** Go to **File > Print > Print Preview** and verify the layout. If fonts have changed, the printer may be substituting unavailable fonts. Stick to system fonts (Calibri, Arial, Times New Roman) that are available on all Windows and Mac systems.

### Template Sections You Cannot Delete

**Problem:** A Word template has sections you do not need (like "Objective" or "References"), but deleting the text leaves behind empty boxes or table rows.
**Fix:** Enable **Show/Hide formatting marks** (Home > paragraph symbol icon) to see hidden table cells and text boxes. Select the entire table row or text box and delete it. If the section is inside a table, right-click the row and select **Delete Rows**.
