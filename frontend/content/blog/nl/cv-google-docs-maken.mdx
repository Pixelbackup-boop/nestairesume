## CV Maken in Google Docs: Complete Gids

Google Docs is een uitstekende, volledig gratis optie voor het maken van je cv. Geen installatie nodig, altijd toegankelijk vanuit de browser en ideaal voor samenwerking. Hier leer je alles over het maken van een cv in Google Docs.

### Voordelen van Google Docs voor je cv

- **Gratis:** geen abonnement of software nodig
- **Overal toegankelijk:** via elke browser, op elke computer
- **Automatisch opgeslagen:** nooit meer een versie kwijtraken
- **Makkelijk delen:** ideaal voor feedback van een loopbaancoach of vriend
- **Versiegeschiedenis:** bekijk eerdere versies van je cv

### De ingebouwde cv-sjablonen in Google Docs

1. Ga naar **docs.google.com**
2. Klik op het **+** symbool (Leeg document) of kies **Meer sjablonen weergeven**
3. Scroll naar de sectie **Cv's**
4. Kies een van de vijf ingebouwde cv-sjablonen:
   - Spearmint (clean, modern)
   - Coral (modern met kleuraccent)
   - Swiss (zakelijk, klassiek)
   - Modern Writer (creatief)
   - Serif (formeel, traditioneel)

Voor de meeste sollicitaties in Nederland is "Spearmint" of "Swiss" de beste keuze — clean en ATS-vriendelijk.

### CV aanpassen in Google Docs

**Lettertypes aanpassen:**
Markeer de tekst → kies een ander lettertype via de letterfontbalk. Stick to: Arial, Calibri, Georgia, Times New Roman.

**Kleur aanpassen:**
Klik op een gekleurde kop → selecteer alle koppen met dezelfde kleur via Format → Alles met hetzelfde formaat selecteren → pas de kleur aan.

**Secties toevoegen of verwijderen:**
Klik voor een nieuwe sectie op de gewenste positie, voeg een regel toe en typ de kopnaam. Verwijder secties door de tekst te selecteren en te verwijderen.

**Foto toevoegen (optioneel):**
Ga naar Invoegen → Afbeelding → upload je professionele foto. Let op: zorg dat de afbeelding geen ATS-inhoud blokkeert.

### Opslaan en versturen als PDF

1. Ga naar **Bestand → Downloaden → PDF-document (.pdf)**
2. Sla het op als: [Voornaam-Achternaam-cv.pdf]
3. Controleer de PDF op opmaakfouten
4. Klaar om te versturen

### Tips voor Google Docs cv's

- Verander de paginagrootte naar A4 (Bestand → Pagina-instelling → A4)
- Gebruik marges van minimaal 1,5 cm
- Vermijd het gebruik van tabellen voor de cv-structuur
- Zet je contactgegevens in de hoofdtekst, niet in de koptekst van het document
