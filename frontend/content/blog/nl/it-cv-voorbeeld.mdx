## IT CV Voorbeeld: Complete Gids voor Developers en IT-Professionals

De Nederlandse IT-markt heeft structureel tekort aan talent — maar dat betekent niet dat je cv er niet toe doet. Een sterk IT-cv laat niet alleen zien wat je kunt coderen; het toont ook hoe je denkt, samenwerkt en waarde toevoegt.

## Structuur van een goed IT-cv

### Sectievolgorde

1. **Persoonlijke gegevens** (naam, GitHub, LinkedIn, e-mail, locatie)
2. **Professionele samenvatting** (je technische identity + carrièredoel)
3. **Technische vaardigheden** (gestructureerd per categorie)
4. **Werkervaring** (chronologisch, projectgericht)
5. **Projecten** (als niet volledig gedekt door werkervaring)
6. **Opleiding en certificeringen**

### De technische vaardighedensectie

Organiseer per categorie:

**Programmeertalen:** Python, JavaScript, TypeScript, Java, Go
**Frameworks & Libraries:** React, Node.js, Django, Spring Boot
**Cloud & DevOps:** AWS (EC2, S3, Lambda), Docker, Kubernetes, GitHub Actions
**Databases:** PostgreSQL, MongoDB, Redis
**Tools:** Git, Jira, Figma, VS Code

Vermeld geen vaardigheidsbars of percentage-beoordelingen — ze zijn subjectief en zeggen niets.

## Werkervaring: projectgericht schrijven

Per functie: 3-5 bullet points gericht op **technische prestaties met impact**:

✅ **Goed:**
> "Ontworpen en geïmplementeerd microservices-architectuur voor betalingssysteem in Node.js + PostgreSQL; verwerkt 2.000 transacties/seconde met 99,9% uptime"

❌ **Slecht:**
> "Werkte aan de backend van onze applicatie"

## Professionele samenvatting voor IT

**Junior developer:**
> "Gepassioneerde full-stack developer (2 jaar) gespecialiseerd in React en Node.js. Ervaring met agile teams via 2 stagebedrijven en 3 persoonlijke projecten. Op zoek naar een junior-positie bij een producttechbedrijf in Nederland."

**Senior developer:**
> "Senior backend engineer (8 jaar) met expertise in distributed systems en cloud-native architectuur op AWS. Geleid 5 productmigraties naar microservices voor scale-ups. Sterk in technisch leiderschap en het begeleiden van junior engineers."

## Certificeringen die waarde toevoegen

- **Cloud:** AWS Solutions Architect, Azure Administrator, Google Cloud Professional
- **DevOps:** Kubernetes CKAD/CKA, Docker Certified Associate
- **Agile:** Scrum Master PSM I/II, Product Owner PSPO
- **Security:** CompTIA Security+, CISSP

## Wat recruiters zoeken in een IT-cv

In gesprekken met Nederlandse IT-recruiters komen deze punten steeds terug:

1. **Concrete projecten** — niet alleen technologieën maar wat je ermee hebt gemaakt
2. **Impact in getallen** — prestatie, performance, gebruikersaantallen
3. **Collaboratieve ervaring** — pull request reviews, pair programming, code reviews
4. **Groei tonen** — van junior naar senior, nieuwe technologieën geleerd
