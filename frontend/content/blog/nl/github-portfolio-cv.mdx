## GitHub op je CV: Hoe Developers hun Portfolio Tonen

Voor developers is GitHub het visitekaartje dat een cv nooit volledig kan zijn. Code spreekt voor zich — en een sterk GitHub-profiel kan je onderscheiden van tientallen andere kandidaten met vergelijkbare werkervaring.

Deze github cv gids biedt praktische tips en concrete voorbeelden om op te vallen.

## Waarom GitHub cruciaal is voor developers

- **85%** van de technische recruiters bekijkt GitHub-profielen bij technische sollicitaties (Stack Overflow Developer Survey)
- GitHub toont je echte code, niet je beschrijving ervan
- Actief bijdragen toont passie en groei buiten werkuren
- Open source bijdragen tonen samenwerkingsvermogen

## Stap 1: Je GitHub-profiel optimaliseren

### Profielafbeelding
Gebruik een professionele foto — dezelfde als op LinkedIn. Geen avatars of anonieme afbeeldingen als je actief solliciteert.

### Biografie
Je GitHub-bio is je elevator pitch. Maximaal 160 tekens:
> "Full-stack developer | React + Node.js | Open source contributor | Amsterdam"

### Pinned repositories
Pin je 6 beste projecten bovenaan je profiel. Criteria voor een goed gepind project:
- Representatief voor je specialisatie
- Volledig README met screenshots
- Actief onderhouden (recente commits)
- Minimaal 1-2 sterren (vraag vrienden of collega's)

## Stap 2: README-bestanden per project

Een goede project-README bevat:
1. **Project naam + korte beschrijving** (1-2 zinnen)
2. **Screenshots of demo-link**
3. **Technologieën** (badge-stijl is populair)
4. **Installatie-instructies**
5. **Gebruik / features**
6. **Jouw bijdrage** (bij samenwerkingsprojecten)

## Stap 3: GitHub vermelden op je cv

### Contactgegevens (bovenaan cv)
Voeg toe naast je e-mail en LinkedIn:
> 🐙 github.com/jouwgebruikersnaam

### Projecten-sectie in je cv
Voeg na "Werkervaring" een sectie "Projecten" of "Portfolio" toe:

**cv-optimizer-tool** | Python, Flask, React | [github.com/jdv/cv-optimizer](https://github.com)
> Webapp die ATS-scores analyseert voor cv-teksten. 200+ GitHub-sterren, 50+ forks.

**e-commerce-microservices** | Node.js, Docker, PostgreSQL
> Microservices architectuur voor webshop. Verwerkt 500 transacties/minuut.

## Stap 4: Actieve bijdragen tonen

Recruiters kijken ook naar je **activiteitsgrafiek** (de groene vakjes). Tips:
- Draag dagelijks of wekelijks bij, ook als het kleine commits zijn
- Draag bij aan open source projecten die je gebruikers
- Schrijf issues en pull request reviews — dat telt ook als bijdrage

## Alternatieve portfolio-opties

Geen representatief GitHub-profiel? Overweeg:
- **Persoonlijke website** met projectbeschrijvingen
- **Notion-portfolio** — snel op te zetten, makkelijk te delen
- **LinkedIn-projecten** sectie — geschikt voor minder technische functies

## Veelgemaakte Fouten Vermijden

Bij het opstellen van je github cv kunnen verschillende veelvoorkomende fouten je kansen ondermijnen. Ten eerste: vermijd generieke beschrijvingen die op elke sollicitant van toepassing zouden kunnen zijn. Kwantificeer je prestaties met specifieke cijfers — "omzetgroei van 23% gerealiseerd" is veel overtuigender dan "bijgedragen aan de groei van de omzet".

Ten tweede: weersta de verleiding om elke functie op te nemen die je ooit hebt bekleed. Focus op de meest relevante 10-15 jaar ervaring. Ten derde: let op consistente opmaak. Verschillende lettertypen, onregelmatige spatiëring en inconsistente datumnotaties wijzen op een gebrek aan oog voor detail.

Een andere veelgemaakte fout is het niet aanpassen van je github cv aan elke sollicitatie. Recruiters herkennen een generiek document onmiddellijk. Pas je profiel, vaardigheden en prestaties aan op de specifieke functie-eisen. Gebruik de trefwoorden uit de vacature op een natuurlijke manier. Controleer ten slotte altijd op spelfouten — dit blijft de snelste manier om afgewezen te worden.

In de Nederlandse arbeidsmarkt is het ook belangrijk om je motivatiebrief af te stemmen op het bedrijf en de specifieke vacature.

## Expertadvies voor 2026

De arbeidsmarkt in 2026 vereist een moderne aanpak van je github cv. Hier zijn bewezen strategieën van HR-professionals:

- **Begin met impactverklaringen.** Start elk opsommingsteken met een sterk actiewerkwoord gevolgd door meetbare resultaten.
- **Optimaliseer voor ATS én mensen.** Gebruik standaard sectiekoppen (Werkervaring, Opleiding, Vaardigheden) en verwerk trefwoorden op een natuurlijke manier.
- **Voeg een vaardighedensectie toe met competentieniveaus.** Technische functies profiteren vooral van een gedetailleerde competentiematrix.
- **Overweeg een projectensectie toe te voegen.** Voor carrièrewisselaars of recent afgestudeerden kan een projectensectie praktische vaardigheden aantonen.
- **Beperk je tot 1-2 pagina's.** Tenzij je meer dan 20 jaar leidinggevende ervaring hebt, toont beknoptheid respect voor de tijd van de lezer.

Onthoud: je github cv is een marketingdocument, geen autobiografie. Elke regel moet zijn plaats rechtvaardigen door de waarde aan te tonen die je biedt aan de potentiële werkgever.

## Stapsgewijze Checklist

Volg deze checklist om ervoor te zorgen dat je sollicitatiedocumenten gepolijst en concurrerend zijn:

1. **Onderzoek het bedrijf** — begrijp de missie, producten en recente ontwikkelingen
2. **Match de trefwoorden** — identificeer de 8-10 belangrijkste trefwoorden uit de vacature en verwerk ze natuurlijk
3. **Kwantificeer prestaties** — vervang vage beschrijvingen door specifieke cijfers, percentages en bedragen
4. **Kies het juiste format** — chronologisch voor een stabiele carrière, functioneel voor carrièreswitch
5. **Schrijf een overtuigende samenvatting** — je professionele profiel moet een elevator pitch van 3-4 zinnen zijn
6. **Grondig proeflezen** — lees je document van achteren naar voren, zin voor zin
7. **Vraag een second opinion** — laat een vertrouwde collega of mentor je definitieve versie beoordelen
8. **Bewaar in het juiste formaat** — PDF behoudt de opmaak op alle apparaten; DOCX alleen als specifiek gevraagd
9. **Strategisch opvolgen** — stuur 5-7 werkdagen na je sollicitatie een korte opvolg-e-mail
10. **Houd je sollicitaties bij** — onderhoud een spreadsheet met bedrijfsnamen, data, contactpersonen en status

Deze systematische aanpak zorgt ervoor dat er niets over het hoofd wordt gezien tijdens je zoektocht naar werk.

## Arbeidsmarkttrends in 2026

Het wervingslandschap blijft zich snel ontwikkelen. Het begrijpen van deze trends geeft je een aanzienlijk concurrentievoordeel:

**AI-screening is nu standaard.** Meer dan 75% van de grote werkgevers gebruikt AI-ondersteunde selectietools. Je documenten moeten geoptimaliseerd zijn voor zowel algoritmische als menselijke beoordeling.

**Competentiegericht werven groeit.** Steeds meer bedrijven schrappen diplomavereisten en richten zich op bewezen vaardigheden. Als je relevante certificeringen of portfolioprojecten hebt, benadruk deze dan.

**Thuiswerken heeft verwachtingen hervormd.** Werkgevers waarderen in toenemende mate zelfmanagement, asynchrone communicatievaardigheden en ervaring met samenwerkingstools.

**Personal branding telt meer.** Je online aanwezigheid — LinkedIn-profiel, persoonlijke website, professioneel blog — wordt vaak bekeken naast je formele sollicitatie.

**Videosollicitaties komen op.** Sommige bedrijven accepteren of vereisen korte introductievideo's. Oefen met het beknopt presenteren van je kwalificaties voor de camera.
