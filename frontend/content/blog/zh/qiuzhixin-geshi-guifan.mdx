## 求职信格式规范：标准排版与专业呈现

求职信的内容固然重要，但格式排版同样影响HR的阅读体验和对你的专业印象。本文详细讲解求职信的标准格式规范，让你的求职信看起来既专业又舒适。

### 中文求职信标准格式

**整体布局：**
- 页面大小：A4（210mm × 297mm）
- 页边距：上下左右各2-2.5cm
- 行间距：1.5倍行距
- 段落间距：段后0.5行

**字体设置：**
- 标题：微软雅黑或黑体，小三号（15pt）
- 正文：宋体或微软雅黑，小四号（12pt）
- 称呼：与正文一致，加粗

**段落格式：**
- 首行缩进2个中文字符
- 段落间空一行（或段后间距）
- 左对齐

### 英文求职信（Cover Letter）格式

**信头格式（Header）：**
```
Your Name
Your Address
City, Province, Zip Code
Phone | Email

Date

Hiring Manager's Name
Company Name
Company Address
```

**正文格式：**
- 不缩进首行
- 段落之间空一行
- 左对齐
- 字体：Arial或Calibri，11pt
- 行间距：1.15倍

### 中英文格式对比

| 要素 | 中文求职信 | 英文Cover Letter |
|------|-----------|-----------------|
| 信头 | 可省略地址 | 完整地址信息 |
| 日期 | 可不写 | 必须写（Month Day, Year） |
| 首行 | 缩进2字符 | 不缩进 |
| 段间距 | 段后0.5行 | 空一行 |
| 称呼 | 尊敬的XX | Dear Mr./Ms. XX |
| 结尾 | 祝好/此致敬礼 | Sincerely/Best regards |
| 签名 | 姓名+日期 | 手写签名+打印姓名 |

### 排版提升技巧

1. **对齐一致** — 所有文字左对齐，不要左右混用
2. **留白充足** — 不要把文字塞满整页，适度留白提升可读性
3. **粗体适度** — 只在关键成就或数据处加粗，不要全篇加粗
4. **颜色克制** — 正文使用黑色，最多用一种深色作为辅助色
5. **打印预览** — 提交前务必在打印预览中检查排版效果

### 求职信文件规范

- 文件格式：PDF优先
- 文件名："张三-求职信-产品经理.pdf"
- 文件大小：不超过2MB
- 不使用压缩包，直接附件发送
