## フリーランスに必要な応募書類

フリーランスとして案件を獲得するには、**自分を売り込む書類**が不可欠です。正社員の転職と異なり、フリーランスは「スキル」と「実績」がすべて。適切な書類を用意することで、案件獲得率が大きく向上します。

## フリーランスの職務経歴書の書き方

### プロジェクト単位で整理する

フリーランスの[職務経歴書](/ja/resume-examples)は、会社単位ではなく**プロジェクト単位**で記載するのが効果的です：

| 項目 | 記載例 |
|------|--------|
| プロジェクト名 | ECサイトリニューアル（大手アパレル企業） |
| 期間 | 2025年4月〜2025年9月（6ヶ月） |
| 役割 | フロントエンドリードエンジニア |
| チーム規模 | 8名（うちフロント3名を統括） |
| 技術スタック | React, TypeScript, Next.js, AWS |
| 成果 | ページ読み込み速度40%改善、CV率15%向上 |

### NDA案件の取り扱い

秘密保持契約がある案件は、以下のように記載します：

- 社名：「大手〇〇企業」（業界＋規模で表現）
- 詳細：技術的なチャレンジと成果に焦点を当てる
- 数値：契約に抵触しない範囲で相対的な改善率を記載

## スキルシートの作成

IT業界のフリーランスに必須のスキルシートは、以下の構成が標準的です：

### 基本構成

1. **基本情報**：氏名、年齢、最寄り駅、稼働可能日
2. **技術スキル一覧**：言語、フレームワーク、DB、インフラ（経験年数付き）
3. **資格**：保有資格の一覧
4. **プロジェクト経歴**：直近から時系列で、各プロジェクトの詳細を記載
5. **自己PR**：得意分野と今後のキャリア方向性

### 技術スキルの書き方

レベルを明確にして記載しましょう：

- **◎（得意）**：実務3年以上、リード経験あり
- **○（可能）**：実務1〜3年、独力で開発可能
- **△（基礎知識）**：学習中、補助的に使用可能

## ポートフォリオの作り方

### オンラインポートフォリオの構成

1. **トップページ**：自己紹介と強みを30秒で伝える
2. **作品一覧**：代表作5〜10点をサムネイル付きで掲載
3. **各作品の詳細ページ**：目的、プロセス、技術、成果を記載
4. **プロフィール**：経歴、スキル、受賞歴
5. **コンタクトフォーム**：問い合わせ先

### ポートフォリオで差をつけるコツ

- **ビフォー・アフター**を見せる（デザイン系）
- **数値で成果を証明**する（マーケティング・開発系）
- **プロセス**を解説する（思考力をアピール）
- **定期的に更新**する（最新のスキルを反映）

## エージェント・クラウドソーシング別の対策

### エージェント経由

正式なスキルシートと職務経歴書が必須。エージェントの書式に合わせて情報を提供し、単価交渉の材料となる実績を明確にしましょう。

### クラウドソーシング

プロフィールページ＝履歴書です。過去の案件の評価、完了率、ポートフォリオリンクが信頼度を左右します。

### 直接営業

提案書＋ポートフォリオで勝負。クライアントの課題を理解し、「あなたの問題を解決できる」ことを具体的に示しましょう。
