## Cara Membuat CV di Google Docs: Panduan Lengkap 2026

Google Docs adalah salah satu alat pembuatan CV yang paling accessible — gratis, berbasis cloud, dan bisa diakses dari perangkat apapun. Tidak perlu install software, tidak perlu lisensi berbayar.

### Keunggulan Google Docs untuk CV

**Gratis dan Accessible:**
- 100% gratis dengan akun Google
- Bisa diakses dari browser, tablet, atau smartphone
- Tidak perlu install Microsoft Office

**Kolaborasi Mudah:**
- Bagikan dengan mentor atau teman untuk mendapat feedback
- Edit bersama secara real-time
- Komentar dan saran langsung di dokumen

**Auto-save:**
- Dokumen tersimpan otomatis setiap perubahan
- Tidak perlu khawatir kehilangan pekerjaan
- Akses riwayat versi dokumen

**Integrasi:**
- Tersimpan di Google Drive
- Mudah dibagikan via Gmail
- Ekspor ke berbagai format

### Langkah-Langkah Membuat CV di Google Docs

#### Cara 1: Menggunakan Template Bawaan Google Docs

1. Buka Google Docs di **docs.google.com**
2. Di halaman utama, klik **Template Gallery** (di pojok kanan atas area template)
3. Scroll ke bagian **"Resumes"**
4. Pilih salah satu template:
   - **Coral** — Warna hangat, modern
   - **Swiss** — Minimalis dan bersih
   - **Serif** — Elegan dengan font serif
   - **Spearmint** — Modern dengan aksen warna
   - **Modern Writer** — Profesional untuk semua bidang
5. Klik template untuk membukanya di tab baru
6. Edit setiap bagian dengan informasi Anda

#### Cara 2: Membuat dari Awal

Jika Anda ingin kontrol penuh atas desain:

1. Buka Google Docs → Blank document
2. Atur ukuran halaman: **File → Page setup → Paper size: A4**
3. Atur margin: 2 cm di semua sisi
4. Mulai dengan nama dan kontak di bagian atas
5. Gunakan **Format → Styles** untuk membuat hierarki heading yang konsisten
6. Tambahkan horizontal line (Insert → Horizontal line) sebagai pemisah bagian

#### Cara 3: Menggunakan Template CV yang Didownload

1. Download template CV gratis dari platform kami atau sumber lain (format .docx)
2. Buka Google Drive
3. Klik **+ New → File Upload**
4. Upload file .docx
5. Klik kanan file yang diupload → **Open with Google Docs**
6. Edit sesuai kebutuhan

### Tips Membuat CV ATS-Friendly di Google Docs

**Pilih Struktur yang Tepat:**
- Satu kolom (paling aman untuk ATS)
- Hindari Text Box — gunakan paragraf biasa
- Hindari Header/Footer untuk informasi penting
- Gunakan bullet points standar (•), bukan ikon custom

**Formatting yang Aman:**
- Font: Arial, Calibri, atau Georgia
- Ukuran teks: 10-12pt
- Heading: 13-14pt, Bold
- Line spacing: 1.0-1.15

**Saat Mengunduh:**
- **File → Download → PDF Document (.pdf)** — bukan "Print to PDF"
- Verifikasi PDF hasilnya sebelum dikirim
- Pastikan semua teks terbaca dengan benar

### Cara Mengunduh CV dari Google Docs

Setelah selesai mengedit:
1. Klik **File** di menu atas
2. Pilih **Download**
3. Pilih format:
   - **PDF Document (.pdf)** — Untuk dikirim ke rekruter ✓
   - **Microsoft Word (.docx)** — Jika rekruter meminta format Word ✓
   - **Rich Text Format (.rtf)** — Kompatibilitas luas ✓
