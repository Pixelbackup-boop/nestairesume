## Curriculo no PowerPoint: Guia para Curriculos Visuais

O PowerPoint nao e apenas para apresentacoes — e uma ferramenta poderosa para criar curriculos visualmente impactantes. Com controle preciso de posicionamento, formas, graficos e tipografia, o PowerPoint permite designs que ferramentas de texto tradicionais nao conseguem.

### Quando Usar PowerPoint para Curriculo

O curriculo em PowerPoint faz sentido para:

- **Designers graficos** — Demonstra habilidade com ferramentas visuais
- **Profissionais de marketing** — Mostra capacidade de comunicacao visual
- **Profissionais de comunicacao** — Layout criativo como diferencial
- **Envio direto a recrutadores** — Quando nao ha triagem ATS

Nao e recomendado para:
- Candidaturas por portais de vagas (Gupy, Catho, InfoJobs)
- Areas corporativas tradicionais (financas, direito, governo)
- Quando a vaga especifica formato .doc ou .pdf padrao

### Como Configurar o PowerPoint para Curriculo

**Configuracao do slide:**
1. Design > Tamanho do Slide > Personalizar
2. Largura: 21 cm | Altura: 29,7 cm (A4)
3. Orientacao: Retrato

**Elementos visuais:**
- Inserir > Formas — Crie barras laterais, separadores e destaques
- Inserir > Icones — Adicione icones para secoes e contato
- Formas com preenchimento de cor para cabecalhos de secao
- Linhas e retangulos como elementos de design

### Exemplo de Layout em PowerPoint

**Zona superior (20% da pagina):**
Faixa colorida com nome, cargo e dados de contato. Icones para telefone, email e LinkedIn.

**Coluna esquerda (35%):**
Foto profissional (opcional), habilidades com barras visuais, idiomas, certificacoes.

**Coluna direita (65%):**
Resumo profissional, experiencia profissional e formacao academica em formato texto.

### Dicas de Design no PowerPoint

1. **Use guias e grade** — Exibir > Linhas de Grade para alinhamento preciso
2. **Agrupe elementos** — Selecione multiplos objetos > Agrupar
3. **Paleta de cores consistente** — Defina 3-4 cores e use em todo o documento
4. **Hierarquia tipografica** — Tamanhos diferentes para nome, titulos e corpo
5. **Espacamento uniforme** — Use distribuir objetos para alinhamento perfeito

### Exportando para PDF

Quando finalizar:
1. Arquivo > Exportar > Criar PDF
2. Verifique o PDF: textos legiveis, cores corretas, alinhamento intacto
3. Confirme que o tamanho e A4
4. Teste abrindo em diferentes dispositivos
