## Criadores de Curriculo Open Source: Ferramentas Gratuitas no GitHub

Para desenvolvedores e profissionais de tecnologia, criadores de curriculo open source oferecem vantagens unicas: codigo auditavel, sem custos ocultos, privacidade garantida e possibilidade de personalizacao total.

Neste guia, apresentamos os melhores projetos open source para criar curriculos profissionais, com dicas de como configura-los e usa-los.

### Por Que Open Source para Curriculos?

Vantagens sobre ferramentas proprietarias:

- **Privacidade** — Seus dados nunca vao para servidores de terceiros
- **Sem custos** — Verdadeiramente gratis, sem paywall ou limites
- **Personalizavel** — Modifique o codigo para suas necessidades
- **Auditavel** — Verifique exatamente o que a ferramenta faz com seus dados
- **Comunidade** — Suporte de milhares de desenvolvedores

### Como Usar um Criador Open Source

**Opcao 1: Use a versao hospedada**
Muitos projetos tem uma versao online pronta. Basta acessar o site e comecar a preencher.

**Opcao 2: Self-hosting**
Para controle total, clone o repositorio e rode localmente:

1. Clone o repositorio do GitHub
2. Instale as dependencias (npm install)
3. Execute o servidor local (npm run dev)
4. Acesse no navegador (localhost)

**Opcao 3: Fork e customize**
Faca um fork do projeto, modifique o codigo para suas necessidades e publique sua versao personalizada.
