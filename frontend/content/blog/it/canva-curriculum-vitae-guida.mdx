## Creare il Curriculum Vitae con Canva: Pro e Contro

Canva è uno strumento di design popolare, ma è la scelta giusta per il curriculum vitae? Ecco un'analisi onesta.

### Vantaggi di Canva per il CV

- Design accattivanti e moderni
- Facile da usare anche senza competenze di grafica
- Molti template gratuiti
- Personalizzazione avanzata (colori, font, layout)
- Risultato visivamente d'impatto

### Svantaggi di Canva per il CV

- Molti template NON sono ATS-friendly
- Il PDF generato può avere problemi di parsing
- Mancano suggerimenti specifici per il contenuto del CV
- I template sono generici (non pensati per il mercato italiano)
- Alcuni template migliori richiedono la versione Pro

### Quando Canva Funziona

| Situazione | Canva è OK? |
|---|---|
| Candidatura via portale ATS | No |
| Candidatura via email diretta | Sì |
| Settore creativo | Sì |
| Settore tradizionale | No |
| Portfolio/CV visivo | Sì |
| CV da stampare | Sì |
