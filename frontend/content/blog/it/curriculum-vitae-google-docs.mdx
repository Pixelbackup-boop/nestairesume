## Curriculum Vitae con Google Docs: Guida Completa

Google Docs è un'alternativa gratuita e potente a Microsoft Word per creare il curriculum vitae. Accessibile da qualsiasi dispositivo, sempre sincronizzato nel cloud.

### Vantaggi di Google Docs per il CV

- **Completamente gratuito** — Serve solo un account Google
- **Accesso ovunque** — Browser, smartphone, tablet
- **Salvataggio automatico** — Nessun rischio di perdere il lavoro
- **Condivisione facile** — Invia link o scarica in PDF/Word
- **Modelli integrati** — Template pronti da personalizzare

### Come Creare il CV con Google Docs

**Passo 1: Accedi alla Galleria Modelli**
Apri docs.google.com → Galleria modelli → sezione Curriculum.

**Passo 2: Scegli un Template**
Seleziona un modello che si avvicina allo stile desiderato. I modelli più semplici sono i migliori per la compatibilità ATS.

**Passo 3: Personalizza il Contenuto**
Sostituisci il testo placeholder con le tue informazioni. Mantieni la formattazione originale per non rovinare il layout.

**Passo 4: Adatta al Mercato Italiano**
- Aggiungi la foto (se non presente nel template)
- Includi l'autorizzazione al trattamento dati
- Verifica che le sezioni siano denominate in italiano

**Passo 5: Scarica e Invia**
File > Scarica > PDF per un risultato professionale.

### Personalizzazione Avanzata

Se i modelli integrati non bastano:

- **Margini:** File > Impostazione pagina > margini personalizzati
- **Font:** Barra degli strumenti > scegli un font professionale
- **Spaziatura:** Formato > Interlinea e spaziatura paragrafi
- **Colori:** Seleziona il testo > cambia colore dall'icona A colorata

### Limiti di Google Docs

Google Docs ha alcune limitazioni rispetto a Word:
- Meno modelli di CV disponibili
- Opzioni di formattazione meno avanzate
- Dipendenza dalla connessione internet (anche se esiste la modalità offline)
- Alcuni font non disponibili
