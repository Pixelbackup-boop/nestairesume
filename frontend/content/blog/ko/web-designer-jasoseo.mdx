## 웹 디자이너 경력 자기소개서: 합격하는 작성 전략

웹 디자이너 경력직 자기소개서는 기술적 역량과 디자인 철학을 모두 보여줘야 합니다. 포트폴리오와 연결되는 효과적인 자소서 작성법을 안내합니다.

### 웹 디자이너 자소서 핵심 구조

**1. 디자인 철학 + 지원 동기**
> "사용자 경험을 최우선으로 생각하는 디자인 철학을 바탕으로, 귀사의 프로덕트 디자인 혁신에 기여하고 싶습니다."

**2. 대표 프로젝트 성과**
> "전자상거래 플랫폼 리디자인 프로젝트에서 UI를 전면 개편하여 장바구니 전환율을 18% 향상시켰습니다."

**3. 기술 역량 + 협업 경험**
> "Figma 기반 디자인 시스템을 구축하고 개발팀과 핸드오프 프로세스를 표준화하여 개발 착수까지의 리드 타임을 40% 단축했습니다."

**4. 기여 비전**
> "귀사의 모바일 앱 사용자 경험 고도화에 데이터 기반 디자인 방법론을 적용하여 사용자 리텐션 향상에 기여하겠습니다."

### 자소서 NG vs OK

**NG:** "디자인에 열정이 있습니다"
**OK:** "사용자 리서치 기반 디자인으로 앱 평점을 3.2→4.5로 개선한 열정을 이어가겠습니다"
