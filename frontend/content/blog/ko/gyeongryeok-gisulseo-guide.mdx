## 경력 기술서 작성법: 상세 가이드와 템플릿

경력 기술서는 이력서의 확장판으로, 각 경력의 구체적인 업무 내용과 성과를 보여주는 핵심 서류입니다. 특히 IT, 엔지니어링, 기획, PM 직군에서 필수적으로 요구됩니다.

이 경력 기술서 템플릿 가이드는 실용적인 팁과 구체적인 예시를 제공합니다.

## 경력 기술서 vs 이력서

| 항목 | 이력서 | 경력 기술서 |
|------|--------|-----------|
| 목적 | 경력·학력 요약 | 업무 상세 기술 |
| 분량 | 1~2페이지 | 2~5페이지 |
| 내용 | 입퇴사일, 회사명, 직급 | 프로젝트 상세, 기술 스택, 성과 |
| 형식 | 정형화 | 자유(프로젝트 기반) |

## 경력 기술서 기본 구성

**1. 프로필 요약** (3~5줄)
전체 경력의 핵심 역량과 전문 분야를 요약합니다.

**2. 경력 상세** (회사별)
각 회사의 프로젝트를 역순으로 정리합니다.

**3. 프로젝트 상세** (각 프로젝트별)
- 프로젝트명·기간
- 프로젝트 개요
- 사용 기술
- 본인 역할
- 성과(정량 수치)

**4. 보유 스킬**
기술 스킬과 비즈니스 스킬을 분류하여 정리합니다.

## 프로젝트 서술 예시

> **전자상거래 플랫폼 구축** | 2024.03~2025.06 | 00주식회사
> - **개요:** 연간 매출 100억 원 규모의 B2C 전자상거래 플랫폼 신규 구축
> - **기술:** React, TypeScript, Node.js, PostgreSQL, AWS (ECS, RDS, CloudFront)
> - **역할:** 백엔드 리드 (팀원 4명), API 설계·구현, DB 스키마 설계
> - **성과:** API 응답 시간 200ms 이내 달성, 월간 주문 처리량 100만 건 안정 운영, 서버 비용 30% 절감

## 노션 경력 기술서 활용

IT·스타트업 업계에서는 노션으로 경력 기술서를 작성하는 트렌드가 확산되고 있습니다:

- **링크 공유** — URL 하나로 전달
- **멀티미디어** — 스크린샷, 다이어그램 삽입 가능
- **하위 페이지** — 프로젝트별 상세 페이지 구성
- **실시간 업데이트** — 언제든 수정 반영

## 경력 기술서 작성 팁

1. 지원 직무와 관련된 프로젝트를 앞쪽에 배치
2. 모든 성과에 정량적 수치 포함
3. "~을 했다"가 아니라 "~을 달성했다"로 서술
4. 기술 스택은 구체적 버전까지 기재

## 흔한 실수와 해결법

경력 기술서 템플릿를 작성할 때 여러 가지 흔한 실수가 기회를 방해할 수 있습니다. 첫째, 어떤 지원자에게나 적용될 수 있는 일반적인 설명을 피하세요. 구체적인 수치로 성과를 정량화하세요 — "매출 성장에 기여"보다 "매출 23% 증가"가 훨씬 설득력 있습니다.

둘째, 지금까지 경험한 모든 직위를 포함하려는 유혹에 저항하세요. 가장 관련성 높은 최근 10-15년의 경력에 집중하세요. 셋째, 서식의 일관성에 주의하세요. 다른 글꼴, 불규칙한 간격, 일관되지 않은 날짜 형식은 세부 사항에 대한 부주의를 나타냅니다.

또 다른 흔한 실수는 각 지원에 맞게 경력 기술서 템플릿를 맞춤화하지 않는 것입니다. 채용 담당자는 일반적인 문서를 즉시 알아봅니다. 자기소개, 기술 섹션, 성과를 채용 공고의 구체적인 요구사항에 맞게 조정하세요.

한국 취업 시장에서는 사진, 나이, 학력 등의 기본 인적사항이 여전히 중요합니다. 자기소개서는 이력서와 별도로 준비하되, 일관된 메시지를 전달해야 합니다.

## 2026년 전문가 조언

2026년 취업 시장은 경력 기술서 템플릿에 대한 현대적인 접근을 요구합니다. 인사 전문가들이 추천하는 전략을 소개합니다:

- **임팩트 있는 문장으로 시작하세요.** 각 항목을 강력한 액션 동사로 시작하고 측정 가능한 결과를 덧붙이세요.
- **ATS와 사람 모두에 최적화하세요.** 표준 섹션 제목(경력사항, 학력, 기술)을 사용하고 키워드를 자연스럽게 통합하세요.
- **숙련도 수준이 포함된 기술 섹션을 포함하세요.** 기술 직군은 각 도구와 기술의 숙련도를 보여주는 역량 매트릭스가 특히 효과적입니다.
- **프로젝트 섹션 추가를 고려하세요.** 경력 전환자나 신입에게 프로젝트 섹션은 실무 능력을 보여줄 수 있는 효과적인 방법입니다.
- **1-2페이지로 제한하세요.** 한국에서도 간결한 이력서가 선호되는 추세입니다. 핵심 내용만 담아 읽는 사람의 시간을 존중하세요.

기억하세요: 경력 기술서 템플릿는 마케팅 문서이지 자서전이 아닙니다. 모든 줄이 잠재적 고용주에게 제공할 가치를 보여줌으로써 그 존재를 정당화해야 합니다.
