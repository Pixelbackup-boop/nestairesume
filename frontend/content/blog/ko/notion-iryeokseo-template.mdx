## 노션 이력서·자기소개서 템플릿: 2026년 활용 가이드

노션(Notion)으로 이력서를 작성하는 트렌드가 IT·스타트업 업계를 중심으로 빠르게 확산되고 있습니다. 노션 이력서의 장단점과 효과적인 활용법을 안내합니다.

### 노션 이력서가 주목받는 이유

- **실시간 업데이트** — 경력이 추가될 때마다 즉시 반영
- **URL 공유** — 링크 하나로 전달, 파일 첨부 불필요
- **멀티미디어** — 프로젝트 스크린샷, 영상, 코드 임베드
- **하위 페이지** — 프로젝트별 상세 정보 별도 정리
- **무료** — 노션 무료 플랜으로 충분히 활용 가능

### 노션 이력서 기본 구조

**메인 페이지:**
1. 프로필 (사진, 이름, 한 줄 소개)
2. 연락처 (이메일, GitHub, LinkedIn)
3. 경력 요약 (3~5줄)
4. 경력 사항 (토글로 상세 펼치기)
5. 프로젝트 (갤러리 뷰 활용)
6. 스킬 (프로그레스바 또는 태그)
7. 학력·자격증

**하위 페이지:**
- 각 프로젝트별 상세 페이지 (스크린샷, 기술 스택, 역할, 성과)

### 노션 이력서의 한계와 보완

**한계:**
- ATS 스크리닝 불가 → 대기업 지원 시 PDF 별도 준비
- 인터넷 필요 → 오프라인 면접 시 프린트본 준비
- 디자인 제한 → 완전한 커스터마이징은 어려움

**보완 전략:**
- [무료 이력서 작성 도구](/ko/builder)로 ATS 대응 PDF 이력서를 별도 준비
- 노션 이력서는 보조 자료(포트폴리오 보충)로 활용
- 두 버전을 병행 운영

### 원티드 × 노션 이력서 활용법

원티드(Wanted)에서 노션 이력서를 효과적으로 활용하는 방법:

1. 원티드 프로필에 노션 URL 첨부
2. 노션 메인 페이지를 경력 요약 중심으로 구성
3. 프로젝트별 상세 하위 페이지 연결
4. 기업 담당자가 관심 가질 핵심 정보를 상단에 배치
