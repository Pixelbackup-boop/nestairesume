## 경력 기술서 템플릿: 노션 경력 기술서 작성법

경력 기술서는 경력직 채용에서 이력서만큼 중요한 문서입니다. 경력 기술서 템플릿을 활용한 효과적인 작성법과 노션 경력 기술서 활용 전략을 안내합니다.

### 경력 기술서란?

이력서가 경력의 '목차'라면, 경력 기술서는 각 경력의 '본문'입니다. 채용 담당자는 경력 기술서를 통해 지원자의 실무 역량을 구체적으로 파악합니다.

### 경력 기술서 필수 항목

각 경력(회사)별로 다음 항목을 포함합니다:

1. **회사 개요** — 회사명, 규모, 업종, 재직 기간
2. **소속/직위** — 부서명, 직위(직급)
3. **담당 업무** — 주요 업무 3-5개 bullet point
4. **핵심 프로젝트** — 프로젝트명, 기간, 역할, 성과
5. **사용 기술** — 도구, 프로그래밍 언어, 플랫폼
6. **성과** — 정량적 수치 (매출 증가율, 비용 절감 등)

### 경력 기술서 템플릿 (프로젝트 서술 예시)

**[프로젝트명] 고객 관리 시스템(CRM) 리뉴얼**
- **기간:** 2024.03 - 2024.09 (7개월)
- **규모:** 개발팀 8명, PM 역할
- **배경:** 기존 CRM의 성능 한계로 고객 데이터 처리 지연 발생
- **역할:** 프로젝트 기획, 요구사항 분석, 일정 관리, 품질 검증
- **사용 기술:** React, Node.js, PostgreSQL, AWS
- **성과:** 데이터 처리 속도 300% 개선, 고객 응대 시간 40% 단축, 연간 운영비 2억 절감

### 노션 경력 기술서 구성법

노션으로 작성하면 온라인 링크로 바로 공유할 수 있어 IT 업계에서 인기입니다:

- **메인 페이지** — 자기 소개, 핵심 역량, 경력 타임라인
- **하위 페이지** — 각 프로젝트 상세 (토글로 펼치기/접기)
- **데이터베이스** — 프로젝트 목록을 표로 정리 (기간, 역할, 기술 태그)
- **포트폴리오 연동** — 실제 결과물 이미지·링크 첨부
