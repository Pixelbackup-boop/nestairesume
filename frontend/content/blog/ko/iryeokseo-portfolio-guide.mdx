## 이력서 포트폴리오 작성법: 두 서류의 시너지를 극대화하는 전략

디자인, 개발, 마케팅, 크리에이티브 직군에서 포트폴리오는 이력서만큼 중요한 서류입니다. 이력서와 포트폴리오를 효과적으로 연결하는 전략을 안내합니다.

### 포트폴리오가 필수인 직군

- **디자인:** UI/UX, 그래픽, 영상, 인테리어
- **개발:** 프론트엔드, 풀스택, 앱 개발
- **마케팅:** 콘텐츠 마케팅, 브랜드 마케팅, SNS
- **크리에이티브:** 카피라이터, 영상 PD, 포토그래퍼

### 이력서 × 포트폴리오 연결 전략

**이력서에서:**
- 포트폴리오 URL을 헤더에 배치
- 프로젝트별 포트폴리오 링크 첨부
- "상세 포트폴리오 참조" 문구 추가

**포트폴리오에서:**
- 이력서의 경력과 일치하는 프로젝트 배치
- 각 프로젝트에 역할·기여·성과 명시
- 이력서에서 언급한 스킬이 실제로 활용된 사례 제시

### PPT 포트폴리오 구성

1. **표지** — 이름, 직무, 연락처
2. **목차** — 프로젝트 목록
3. **프로젝트별 2~3슬라이드**
   - 개요·목표
   - 과정·역할
   - 결과·성과
4. **스킬 요약** — 사용 도구 목록
5. **마무리** — 연락처, 감사 인사

### 온라인 포트폴리오 플랫폼

| 플랫폼 | 적합 직군 | 비용 |
|--------|----------|------|
| Behance | 디자인 전반 | 무료 |
| Dribbble | UI/UX 디자인 | 무료/유료 |
| GitHub | 개발 | 무료 |
| 노션 | 기획, PM, 개발 | 무료 |
| 개인 사이트 | 전 직군 | 호스팅 비용 |
