## ATS 이력서 작성 가이드: 서류 전형을 뚫는 완벽한 전략

ATS(지원자 추적 시스템)를 모르고 이직 활동을 하고 있지 않으신가요? 대기업의 90% 이상이 ATS를 도입했으며, 당신의 이력서는 채용 담당자의 눈에 닿기 전에 AI의 스크리닝을 먼저 거칩니다.

### ATS의 작동 원리

ATS는 다음과 같은 프로세스로 지원 서류를 처리합니다:

1. **파싱(분석)** — 이력서에서 텍스트를 추출
2. **키워드 매칭** — 채용 조건과의 일치도 계산
3. **스코어링** — 지원자를 점수순으로 랭킹
4. **필터링** — 기준 미달 지원자 제외

### ATS 대응 5대 원칙

**1. 키워드 최적화**
채용 공고에 명시된 스킬, 자격, 경력 연수 등의 키워드를 이력서에 자연스럽게 넣으세요.

**2. 심플한 포맷**
다단 레이아웃, 텍스트 박스, 헤더/푸터 내 텍스트를 피하세요.

**3. 표준적인 섹션 제목**
"경력 사항", "학력", "스킬", "자격증" 등 일반적인 제목을 사용하세요.

**4. PDF 형식 제출**
PDF가 가장 안전합니다. Word(DOCX)도 대부분 호환되지만 레이아웃 깨짐 위험이 있습니다.

**5. 약어와 정식 명칭 병기**
"AWS(Amazon Web Services)", "CRM(고객 관계 관리)" 형태로 작성하세요.

### ATS 대응 체크리스트

- [ ] 채용 공고 키워드가 이력서에 포함됨
- [ ] 심플한 단일 컬럼 레이아웃 사용
- [ ] 표, 그래픽, 텍스트 박스 미사용
- [ ] 표준 폰트(나눔고딕, 맑은 고딕) 사용
- [ ] PDF 형식으로 저장
- [ ] 파일명이 "이름_이력서.pdf"처럼 명확
- [ ] 헤더/푸터에 중요 정보 미배치
