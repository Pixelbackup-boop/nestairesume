## 개발자 이력서 작성 가이드: IT 엔지니어를 위한 완벽 템플릿

개발자 이력서는 일반 이력서와 다른 고유한 요소들이 있습니다. 기술 스택 표기, 프로젝트 경험 서술, GitHub·포트폴리오 연동 등 개발자에게 특화된 작성법을 안내합니다.

### 개발자 이력서의 특수 요소

일반 이력서와 달리 개발자 이력서에 포함해야 할 항목:

- **기술 스택(Tech Stack)** — 언어, 프레임워크, 도구
- **프로젝트 경험** — 규모, 역할, 성과
- **GitHub/포트폴리오 URL** — 코드·결과물 링크
- **오픈소스 기여** — 있다면 큰 플러스
- **블로그/기술 글** — 기술 이해도 어필

### 기술 스택 기재 방법

**권장 분류:**

**Languages:** JavaScript, TypeScript, Python, Java
**Frontend:** React, Next.js, Vue.js, Tailwind CSS
**Backend:** Node.js, Express, Spring Boot, Django
**Database:** PostgreSQL, MongoDB, Redis
**Cloud/DevOps:** AWS, Docker, Kubernetes, CI/CD
**Tools:** Git, Jira, Figma, Postman

### 프로젝트 경험 서술 공식

> **[프로젝트명]** — [기간]
> 기술 스택: [사용 기술 나열]
> 역할: [담당 역할]
> 성과: [정량적 결과]

**예시:**
> **전자상거래 플랫폼 리뉴얼** — 2025.03~2025.12
> React, TypeScript, Node.js, AWS, PostgreSQL
> 프론트엔드 리드 (팀원 5명)
> 페이지 로딩 속도 40% 개선, 월간 사용자 50만 명 서비스 안정 운영

### 경력별 이력서 전략

**신입·주니어 (0~3년):**
- 부트캠프/학교 프로젝트도 포함
- 기술 학습 의지 강조
- GitHub 활동 적극 어필

**미드 레벨 (3~7년):**
- 프로젝트 리딩 경험 강조
- 기술적 의사결정 사례 포함
- 멘토링 경험 언급

**시니어 (7년+):**
- 아키텍처 설계 경험 강조
- 비즈니스 임팩트 수치 포함
- 팀 빌딩·조직 기여 사례
