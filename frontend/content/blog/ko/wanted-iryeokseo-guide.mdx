## 원티드 이력서 작성법: IT·스타트업 채용 프로필 최적화

원티드(Wanted)는 IT·스타트업 업계의 대표 채용 플랫폼입니다. 원티드의 프로필 시스템을 이해하고, 매칭 성공률을 높이는 이력서 전략을 안내합니다.

### 원티드 프로필 시스템 이해

원티드는 기존 잡포털과 다른 프로필 기반 시스템입니다:

- **프로필 = 이력서** — 별도 이력서 업로드 없이 프로필이 곧 이력서
- **AI 매칭** — 기술 스택·경력 기반 자동 매칭
- **외부 링크** — 노션, GitHub, 포트폴리오 URL 첨부 가능
- **추천 보상** — 지인 추천 시 보상금 제도

### 원티드 프로필 최적화 5가지

**1. 기술 스택 태그 완벽히 기입**
사용 가능한 기술을 빠짐없이 태그하세요. 매칭 알고리즘의 핵심 데이터입니다.

**2. 경력 서술 성과 중심으로**
"~업무 담당" 대신 "~성과 달성"으로 작성하세요.

**3. 노션 이력서 연동**
프로젝트 상세 정보를 노션에 정리하고 URL을 프로필에 첨부하세요.

**4. GitHub·포트폴리오 연결**
개발자는 GitHub 링크, 디자이너는 포트폴리오 URL을 반드시 연결하세요.

**5. 정기적 프로필 업데이트**
월 1회 이상 업데이트하세요. 최근 활동이 매칭 알고리즘에 영향을 미칩니다.
