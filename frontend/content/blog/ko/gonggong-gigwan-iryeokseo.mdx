## 공공기관 이력서 작성법: NCS 기반 서류 전략

공공기관(공기업) 채용은 NCS(국가직무능력표준) 기반의 블라인드 채용으로 진행됩니다. 공공기관 이력서의 특수한 작성 요령과 서류 전형 통과 전략을 안내합니다.

### 공공기관 채용 프로세스

1. **채용 공고 확인** — NCS 직무 분류, 지원 자격
2. **온라인 입사지원** — NCS 기반 입사지원서 작성
3. **서류 전형** — 블라인드 평가, 직무 역량 중심
4. **필기 전형** — NCS 직업기초능력평가, 직무수행능력평가
5. **면접 전형** — 경험 면접, 상황 면접, 발표 면접
6. **최종 합격** — 신체검사, 신원조회

### NCS 기반 입사지원서 작성법

**교육사항:**
- 학교명 대신 전공 분야와 이수 과목 중심
- NCS 직무와 관련된 교육·자격만 기재
- "경영학 전공, 재무관리·회계원리·경영전략 이수"

**경력·경험사항:**
- NCS 직무 능력 단위와 연결하여 서술
- STAR 기법 + 정량적 성과
- "인턴십에서 고객 데이터 분석 업무 수행, 분석 보고서 30건 작성"

**자기소개서:**
- 항목별 글자 수 정확히 준수
- 직무 관련 경험을 구체적 에피소드로
- 해당 기관의 미션·비전과 연결

### 공공기관 직무 역량 서술 예시

**행정 직군:**
> 대학 행정 인턴으로 학사 관리 시스템 개선 프로젝트에 참여했습니다. 수강신청 프로세스를 분석하여 3단계를 2단계로 축소하는 방안을 제안, 처리 시간 30% 단축에 기여했습니다.

**기술 직군:**
> 졸업 프로젝트에서 IoT 센서 기반 시설물 안전 모니터링 시스템을 개발했습니다. Python으로 센서 데이터를 수집·분석하고, 이상 징후 자동 알림 기능을 구현하여 교수님으로부터 최우수 평가를 받았습니다.
