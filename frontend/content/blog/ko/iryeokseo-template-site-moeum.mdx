|------|--------|------|----------|------|

### 사이트별 상세 비교

**AI 이력서 빌더 — 종합 1위:**
- AI가 경력을 분석해 프로페셔널한 문장 자동 생성
- ATS(지원자 추적 시스템) 최적화 키워드 추천
- [16가지 프리미엄 템플릿](/ko/resume-templates) 제공
- PDF, DOCX 즉시 다운로드

**워크넷 — 공공기관 지원용:**
- 정부 공식 표준 이력서 양식
- HWP, DOC 형식 무료 다운로드
- 공공기관·공기업 지원에 필수

**캔바 — 디자인 직군용:**
- 수백 종의 시각적 템플릿
- 드래그 앤 드롭 편집
- ATS 비호환이 단점

### 이력서 템플릿 선택 기준

1. **ATS 호환성** — 대기업·외국계 지원 시 필수
2. **직군 적합성** — 업종에 맞는 톤·레이아웃
3. **편집 용이성** — 수정이 쉬운 형식
4. **다운로드 형식** — PDF, DOCX, HWP 지원 여부
5. **AI 기능** — 문장 생성, 키워드 최적화
