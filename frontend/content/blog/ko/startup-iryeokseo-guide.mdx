## 스타트업 이력서 작성법: 대기업과 다른 합격 전략

스타트업 채용은 대기업과 평가 기준이 다릅니다. 자유 양식, 실무 능력 중심, 문화 적합성을 중시하는 스타트업 이력서 작성 전략을 안내합니다.

### 스타트업이 이력서에서 보는 것

| 대기업 중시 | 스타트업 중시 |
|------------|-------------|
| 학벌, 학점 | 사이드 프로젝트, 포트폴리오 |
| 어학 점수 | 실무 기술, 도구 숙련도 |
| 정형화된 양식 | 자유 양식, 개성 |
| 조직 경험 | 자기 주도성, 문제 해결 |
| 대기업 경력 | 0→1 경험, 성장 속도 |

### 스타트업 이력서 구성 추천

**1. 핵심 역량 한 줄 요약**
> "풀스택 개발자 | 0→1 서비스 3건 런칭 | React·Node.js·AWS"

**2. 프로젝트 중심 경력**
- 회사명보다 프로젝트와 성과에 집중
- "무엇을 했다"보다 "무엇을 만들었다"
- 사용자 수, 매출, 개선률 등 지표 필수

**3. 사이드 프로젝트·오픈소스**
- GitHub 프로필 링크
- 개인 프로젝트 성과 (다운로드 수, 스타 수)
- 블로그·기술 글 링크

**4. 기술 스택 (상세)**
- 프로그래밍 언어, 프레임워크, 도구별 분류
- 숙련도 표시 (예: React 상, Vue 중)
- 최근 학습 중인 기술도 포함

### 노션 이력서 vs PDF 이력서

**노션 이력서 (IT·스타트업 추천):**
- URL 공유로 즉시 접근
- 토글, 데이터베이스, 링크 활용
- 포트폴리오 통합 관리

**PDF 이력서 (범용):**
- ATS 시스템 호환
- 오프라인 열람 가능
- 형식 보장

→ 두 가지 모두 준비하는 것이 이상적
