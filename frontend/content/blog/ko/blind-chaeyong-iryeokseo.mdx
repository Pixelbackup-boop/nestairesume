## 블라인드 채용 이력서 작성법: 역량 중심 전략

블라인드 채용은 한국 공공기관에서 의무화된 채용 방식으로, 학력·출신·외모 대신 직무 역량만으로 평가합니다. 블라인드 채용 이력서의 핵심 작성법을 안내합니다.

### 블라인드 채용에서 기재 금지 항목

| 기재 금지 | 대체 표현 |
|-----------|----------|
| 학교명 | "4년제 대학교" |
| 사진 | 첨부하지 않음 |
| 생년월일 | 기재하지 않음 |
| 성별 | 기재하지 않음 |
| 가족 관계 | 기재하지 않음 |
| 출신 지역 | 기재하지 않음 |
| 신체 조건 | 기재하지 않음 |

### 블라인드 채용 이력서 구성

**1. 직무 관련 교육 이수**
- 학교명 대신 전공명과 이수 과목 중심
- 직무 관련 교육, 자격증, 온라인 과정

**2. 직무 관련 경험**
- NCS(국가직무능력표준) 기반 직무 역량 서술
- 인턴, 프로젝트, 봉사활동 등 직무 연관 경험
- STAR 기법으로 구체적 성과 서술

**3. 자격증·기술**
- 직무 관련 국가공인 자격증
- 어학 능력 (등급 또는 점수)
- 직무 관련 기술·도구

### NCS 기반 직무 역량 서술법

블라인드 채용은 NCS(국가직무능력표준)에 따라 직무 역량을 평가합니다:

- **직무 수행 능력** — 해당 직무에 필요한 핵심 역량
- **직업 기초 능력** — 의사소통, 문제 해결, 조직 이해 등
- **경험·경력** — 직무와 직접 관련된 경험만 기재

**서술 예시:**
> 공공 데이터 분석 프로젝트에서 Python과 SQL을 활용하여 민원 데이터 50만 건을 분석, 민원 처리 시간 25% 단축 방안을 도출했습니다.
