Data analytics hiring has one consistent test: can you take a business question, write a query to answer it, and communicate the result in a way that drives a decision? Your resume must demonstrate all three capabilities — not just list the tools you know.

Here is how to write a data analyst resume that shows you are analytically capable AND business-aware.

## What Data Analyst Hiring Managers Look For

Analytics hiring varies significantly by company type and role level:

**Startup (small analytics team):** SQL fluency, Python for automation, ability to work independently, business context understanding
**Mid-size (dedicated analytics):** Domain expertise (marketing analytics, product analytics, financial analytics), collaboration with engineers and PMs, BI tool mastery
**Enterprise (large analytics org):** Specialization, scale (billions of rows, complex systems), data governance and documentation

The universal screen: **SQL proficiency at the depth required for the role.** Junior roles need SELECT, JOINs, aggregations, and window functions. Senior roles need query optimization, complex CTEs, stored procedures, and schema design.

## Data Analyst Skills

### Core Technical Skills
- **SQL** — most important; specify depth (SELECT/JOIN/subquery vs. window functions/CTEs vs. query optimization)
- **Python** (pandas, NumPy, matplotlib, seaborn, scikit-learn for ML-adjacent roles)
- **R** (for statistical analysis and modeling)
- **Excel / Google Sheets** (VLOOKUP, pivot tables, Power Query, advanced formulas)

### Business Intelligence and Visualization
- Tableau, Power BI, Looker (LookML), Mode, Metabase, Redash
- Google Data Studio / Looker Studio
- Jupyter Notebooks for exploratory analysis

### Data Engineering Basics (Nice-to-Have)
- dbt (data build tool)
- Airflow for workflow orchestration
- BigQuery, Snowflake, Redshift, Databricks
- Python ETL scripting

### Statistical Methods
- A/B testing and experimentation design
- Regression analysis (linear, logistic)
- Cohort analysis
- Funnel analysis
- Churn modeling
- Time series analysis

### Domain-Specific Analytics
- **Product analytics:** DAU/MAU, retention, funnel conversion, feature adoption
- **Marketing analytics:** CAC, LTV, attribution modeling, campaign ROI
- **Financial analytics:** FP&A, cost analysis, forecasting, variance analysis
- **Operations analytics:** Supply chain optimization, demand forecasting, efficiency metrics

## Format Tips for Data Analyst Resumes

### 1. List SQL Depth, Not Just "SQL"
"SQL" says you know the word. "SQL (advanced — BigQuery, Snowflake; window functions, CTEs, query optimization, 50M+ row datasets)" shows you know the tool. Hiring managers with technical backgrounds will probe whatever you list, so be precise.

### 2. Separate Languages From BI Tools
Data analysts have two distinct technical skill categories: programming languages (SQL, Python, R) and BI/visualization tools (Tableau, Power BI, Looker). Organize them separately so both signal clearly.

### 3. Include GitHub for Entry-Level Candidates
New graduates and career changers should add a GitHub URL to their header if they have relevant projects. A clean repo with 2-3 analysis projects (documented with README files) significantly helps compensate for limited professional experience.

### 4. Show Domain Specialization
"Marketing analytics" or "product analytics" tells a hiring manager more than "data analysis" alone. If you have focused on a specific domain (e-commerce, fintech, healthcare, SaaS), call it out.

### 5. Translate Data Work to Business Outcomes
Every analysis bullet should end with what the analysis was used for or what decision it influenced — not just what you did technically. "Built a dashboard" → "Built a dashboard used by the executive team to make $2M in quarterly budget allocation decisions."

## Portfolio Projects for Entry-Level Analysts

If you are entering the field, build and link 2-3 portfolio projects on GitHub:

**Project 1: SQL Analysis**
Take a public dataset (NYC taxi trips, Stack Overflow survey, Kaggle competition) and write a multi-step SQL analysis answering a business question. Document your approach and findings in a README.

**Project 2: Python + Visualization**
Build a Python analysis with pandas and matplotlib or seaborn. A cohort analysis, funnel analysis, or churn prediction model all demonstrate relevant skills.

**Project 3: Dashboard**
Create a Tableau Public or Power BI dashboard on a public dataset. Share the public URL in your GitHub README and resume portfolio link.
