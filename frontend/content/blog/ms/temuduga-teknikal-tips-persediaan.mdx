## Temuduga Teknikal: Panduan Persediaan untuk Jawatan IT dan Kejuruteraan di Malaysia

Temuduga teknikal di Malaysia semakin kompetitif dengan pertumbuhan industri teknologi. Sama ada anda memohon di Grab, Shopee, atau startup tempatan, panduan tips persediaan temuduga teknikal ini membantu anda bersedia.

### Jenis Temuduga Teknikal di Malaysia

**1. Temuduga Coding/Programming**
Menyelesaikan masalah coding secara langsung menggunakan papan putih atau platform online.

**2. Temuduga System Design**
Mereka bentuk sistem skala besar — biasa untuk jawatan senior.

**3. Temuduga Berdasarkan Projek**
Membincangkan projek terdahulu secara mendalam — keputusan teknikal, cabaran, dan pengajaran.

**4. Temuduga Take-Home Assignment**
Menyiapkan tugasan teknikal di rumah dalam tempoh tertentu.

### Persediaan Temuduga Coding

**Struktur Data yang Perlu Dikuasai:**
- Array dan Linked List
- Stack dan Queue
- Hash Map dan Hash Set
- Binary Tree dan BST
- Graph

**Algoritma yang Perlu Difahami:**
- Sorting (Quick Sort, Merge Sort)
- Searching (Binary Search)
- BFS dan DFS
- Dynamic Programming (asas)
- Two Pointers, Sliding Window

**Platform Latihan:**
- LeetCode — fokus pada soalan Easy dan Medium
- HackerRank — baik untuk permulaan
- CodeSignal — digunakan oleh beberapa syarikat Malaysia

### Teknik Menjawab Soalan Coding

1. **Faham soalan** — tanya soalan penjelasan sebelum mula
2. **Bincang pendekatan** — jelaskan strategi sebelum menulis kod
3. **Mulakan dengan brute force** — kemudian optimumkan
4. **Tulis kod bersih** — penamaan yang baik, komen yang berguna
5. **Uji dengan contoh** — trace through kod dengan input ujian
6. **Analisis kompleksiti** — Time dan Space complexity

### Temuduga System Design

Untuk jawatan senior di Malaysia (Grab, Shopee, dll.):

**Topik biasa:**
- Reka bentuk URL shortener
- Reka bentuk sistem chat
- Reka bentuk sistem e-dagang
- Reka bentuk newsfeed

**Langkah menjawab:**
1. Fahami keperluan dan skop
2. Anggaran trafik dan kapasiti
3. Reka bentuk API
4. Reka bentuk pangkalan data
5. Reka bentuk arsitektur tingkat tinggi
6. Bincang trade-offs dan bottlenecks

### Tips Khas Temuduga Teknikal Malaysia

1. Syarikat Malaysia sering menggabungkan soalan teknikal dengan soalan tingkah laku
2. Kemahiran soft skill dinilai walaupun dalam temuduga teknikal
3. Tunjukkan pemahaman tentang produk syarikat
4. Bersedia untuk temuduga dalam Bahasa Inggeris
5. Portfolio GitHub atau projek peribadi memberikan kelebihan besar

### Selepas Temuduga Teknikal

Buat catatan tentang soalan yang ditanya dan bagaimana anda menjawab. Ini membantu untuk temuduga seterusnya. Pastikan resume anda menonjolkan kemahiran teknikal yang relevan menggunakan [pembina resume](/ms/builder).
