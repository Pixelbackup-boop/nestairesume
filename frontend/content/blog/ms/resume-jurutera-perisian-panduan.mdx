## Resume Jurutera Perisian: Panduan untuk Pasaran Teknologi Malaysia 2026

Resume jurutera perisian Malaysia perlu menunjukkan kemahiran teknikal, pengalaman projek, dan impak yang dihasilkan. Dengan pertumbuhan pesat sektor teknologi di Kuala Lumpur, Penang, dan Cyberjaya, persaingan untuk jawatan jurutera perisian semakin sengit.

### Struktur Resume Jurutera Perisian

**Header:**
- Nama, e-mel, nombor telefon, lokasi
- Pautan LinkedIn, GitHub, dan portfolio (jika ada)

**Ringkasan teknikal:**
> Jurutera Perisian Full-Stack dengan 4 tahun pengalaman membina aplikasi web berskala besar menggunakan React, Node.js, dan AWS. Memimpin pembangunan platform e-dagang yang melayani 50,000+ pengguna aktif bulanan dengan uptime 99.9%.

### Kemahiran Teknikal — Format yang Berkesan

Susun kemahiran mengikut kategori:

**Bahasa:** JavaScript, TypeScript, Python, Java, SQL
**Frontend:** React, Next.js, Vue.js, Tailwind CSS
**Backend:** Node.js, Express, Django, Spring Boot
**Pangkalan Data:** PostgreSQL, MongoDB, Redis
**DevOps:** Docker, Kubernetes, AWS, CI/CD (GitHub Actions)
**Alat:** Git, Jira, Figma, Postman

### Projek — Cara Menulisnya

Untuk setiap projek, gunakan format STAR:

**Projek:** Platform Pengurusan Inventori (2025)
- **Teknologi:** React, Node.js, PostgreSQL, Docker
- **Peranan:** Lead Developer (pasukan 4 orang)
- **Kesan:** Mengurangkan masa pemprosesan pesanan dari 15 minit ke 2 minit, menjimatkan 200+ jam kerja sebulan untuk pelanggan

### Pengalaman Kerja — Pencapaian, Bukan Tugas

Gantikan tugas generik dengan pencapaian:

- ❌ "Menulis kod dan membuat ujian"
- ✅ "Membina API pembayaran yang memproses RM2 juta transaksi sebulan dengan kadar ralat 0.01%"

- ❌ "Menyelenggara pangkalan data"
- ✅ "Mengoptimumkan query SQL yang mengurangkan masa respons API dari 3s ke 200ms, meningkatkan skor Lighthouse sebanyak 25 mata"

### Syarikat Teknologi Teratas di Malaysia

Resume anda mungkin dinilai oleh:
- **Unicorn:** Grab, Carsome, GoTo
- **MNC:** Google, Intel, AMD, Motorola (Penang)
- **Bank digital:** GXBank, Boost, Touch 'n Go
- **Startup:** Speedhome, Jirnexu, StoreHub, Fave

Setiap kategori mempunyai jangkaan berbeza — sesuaikan resume anda.

### Tips Lulus Saringan ATS Teknologi

1. Gunakan kata kunci daripada deskripsi jawatan
2. Nyatakan teknologi dengan nama tepat (React.js, bukan "framework JS")
3. Elakkan jadual atau grafik — ATS tidak boleh membacanya
4. Simpan dalam format PDF
5. Gunakan tajuk bahagian standard (Pengalaman, Kemahiran, Pendidikan)

### Kesilapan Biasa Resume IT

1. Menyenaraikan 20+ teknologi tanpa tahap kemahiran
2. Tiada pautan ke GitHub atau portfolio
3. Fokus kepada tugas, bukan kesan
4. Resume terlalu panjang (3+ muka surat)
5. Tidak menyesuaikan resume untuk setiap jawatan
