## GitHub Portföy CV'si: Yazılım Geliştiriciler İçin Kapsamlı Rehber

GitHub portföy cv'si, teknik pozisyonlar için başvururken CV'nizin canlı eki ve en güçlü referans kaynağınızdır.

### Neden GitHub + CV Kombinasyonu?

Yazılım mühendisleri için işveren değerlendirme süreci:
1. CV'ye bakış (ilk 30 saniye)
2. GitHub profili incelemesi — kod kalitesi, proje çeşitliliği, aktivite
3. LinkedIn veya referans kontrolü
4. Teknik mülakat

GitHub profiliniz olmadan "Python, Django, AWS" iddiaları kanıtsız kalır.

### GitHub Profili Optimizasyonu: 8 Adım

**Adım 1: Profil Fotoğrafı ve Bio**
Profesyonel fotoğraf + bio örneği: "Backend Developer | Python, FastAPI, PostgreSQL"

**Adım 2: Pinned Repositories**
6 pinned repo seçin: 2-3 tamamlanmış proje, 1-2 aktif geliştirdiğiniz, 1 araç veya kütüphane.

**Adım 3: README Dosyaları**
Her önemli repoda: proje özeti, teknoloji stack'i, kurulum talimatları, demo linki.

**Adım 4: Profil README**
github.com/kullaniciadı/kullaniciadı isimli özel repo ile profil tanıtım kartı oluşturun.

**Adım 5: Commit Geçmişi**
Kaliteli ve anlamlı commit'ler tercih edin. Düzenli aktivite önemli bir sinyaldir.

**Adım 6: Açık Kaynak Katkılar**
Doc düzeltmesi, test ekleme, küçük bug fix — toplulukla uyumu gösterir.

**Adım 7: Topics Kullanın**
Repolara topics ekleyin: python, fastapi, rest-api — keşfedilmenizi kolaylaştırır.

**Adım 8: Temizlik**
Test ve anlamsız isimli repoları, yarım kalmış empty repoları gizleyin.
