## CV AI/ML Engineer: Cách Trình Bày Chuyên Nghiệp

AI và Machine Learning là lĩnh vực hot nhất tại Việt Nam 2026. CV tốt giúp bạn nổi bật trong mắt các công ty AI hàng đầu.

### Cấu Trúc CV AI/ML

1. **Thông tin cá nhân** — Tên, email, GitHub, Google Scholar, Kaggle
2. **Tóm tắt** — Lĩnh vực chuyên sâu (NLP, CV, RecSys), tech stack
3. **Kỹ năng kỹ thuật** — Frameworks, languages, tools, cloud
4. **Kinh nghiệm** — Dự án ML end-to-end, metrics, impact
5. **Publications/Projects** — Papers, competitions, open-source
6. **Học vấn** — Bằng cấp, GPA, thesis topic

### Kỹ Năng AI/ML Quan Trọng

**ML Frameworks:** PyTorch, TensorFlow, scikit-learn, Hugging Face
**Languages:** Python, SQL, C++ (cho performance-critical)
**Data:** Pandas, Spark, Airflow, dbt
**MLOps:** Docker, MLflow, Kubeflow, Weights & Biases
**Cloud:** AWS SageMaker, GCP Vertex AI, Azure ML
**LLM:** LangChain, OpenAI API, RAG, Fine-tuning

### Ví Dụ Bullet Points

- "Phát triển model NLP tiếng Việt đạt F1-score 92% cho bài toán sentiment analysis trên 1M reviews"
- "Triển khai recommendation engine tăng CTR 25% cho sàn e-commerce 5M users"
- "Tối ưu inference latency giảm 70% bằng model quantization và TensorRT"
- "Xây dựng data pipeline xử lý 10TB data/ngày trên Spark cluster"
